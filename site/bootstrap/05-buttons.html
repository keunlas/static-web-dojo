跳到正文

布局与文字都齐了，接下来是页面上的“行动点”：按钮让人点，徽章给人看数字，提示框给人递消息。 三件套一起练，页面就有了生气。

本式要点
  • btn 本体类必须配配色类，8 色各有语义
  • btn-outline-* 描边变体、btn-lg/btn-sm 尺寸、disabled 与 active 状态
  • btn-group 按钮组与 badge 徽章的配色、胶囊与嵌套
  • alert 提示框：8 色、role="alert" 与可关闭写法

按钮：btn 与八色

按钮的写法是“本体 + 配色”：btn 负责造型（圆角、内边距、悬停效果）， btn-* 负责颜色。只写 btn 是灰白色裸按钮。8 色各有用武之地：

配色类语义
btn-primary主操作、品牌色（本站皮肤把它染成了朱砂）
btn-secondary次要操作，低调陪衬
btn-success成功、保存、确认
btn-danger危险动作：删除、退出登录
btn-warning提醒：可能有风险，先确认
btn-info说明、中性提示
btn-light浅色按钮，适合深色背景上
btn-dark深色按钮，稳重
例 1 · 全套按钮色卡：上排实心，下排描边

btn-outline-* 是描边变体：白底彩边，悬停时才填色。它视觉上更轻， 适合与主按钮同台的次要动作——一个页面里“实心”最好只有一枚，其余用描边。 （outline-light 是浅色描边，本页浅底上看不清，深色页面上才会用它。）

尺寸与状态

尺寸三档：btn-lg 大、btn-sm 小，什么都不写是默认中号。 状态两种：disabled 禁用（普通 button 元素直接用 disabled 属性）；active 表示“当前选中 / 按下”， 常配 aria-pressed="true" 让读屏知道这是按下状态。

心法：链接式按钮的禁用三件套

如果按钮是用 <a> 标签做的（如 <a class="btn btn-primary">）， 它没有 disabled 属性。要写三件套：class="btn disabled" 管样式、 aria-disabled="true" 告诉读屏、tabindex="-1" 挡开键盘焦点。

例 2 · 尺寸三档与两种状态
链接式禁用

摸一下那枚“链接式禁用”：鼠标点不动、Tab 键也到不了——这就是三件套的完整效果。 只写 disabled 类的话，键盘照样能聚焦并触发它。

按钮组：btn-group

把一组相关的按钮包进 btn-group，它们会拼成一条，圆角只留在两端。 无障碍建议加 role="group" 与 aria-label 说明用途； 整组尺寸用 btn-group-lg / btn-group-sm 控制。 按钮组里嵌徽章是最常见的组合——工具栏按钮带未读数。

例 3 · 按钮组 + 徽章组合

第一组是“单选切换”的雏形（active 标记当前项），第二组是带计数的工具栏。 btn-group 里的按钮要挨在一起，所以不要给中间的按钮加外间距。

徽章：badge

badge 是行内的小标记，写法同样是“本体 + 配色”。Bootstrap 5.2 起推荐 text-bg-*——背景色与文字色一次配好，自动保证对比度。加 rounded-pill 变胶囊形。徽章可以嵌进标题、按钮、列表项里。

例 4 · 徽章三态：嵌标题、八色、胶囊

修行进度 第 5 式

primary secondary success danger warning info light dark

胶囊徽章： 99+ 已完成

嵌在标题里的徽章会跟着标题字号缩小一圈，所以 badge 不需要单独调字号； 未读数、状态标签、版本号，都是它的经典岗位。

提示框：alert

alert 是横贯一行的消息横幅，写法仍是“本体 + 配色”（alert + alert-success 等 8 色，语义与按钮色一致）。务必加 role="alert"—— 它告诉屏幕阅读器“这是重要消息，请立即播报”，是提示框无障碍的命门。

可关闭版三件套：alert-dismissible（给关闭按钮留出位置）+ 关闭按钮 （btn-close 加 data-bs-dismiss="alert"）+ 可选 fade show （出现与关闭时淡入淡出）。data-bs-* 机制由 bootstrap bundle 自动接管，一行 JS 都不用写。

例 5 · 可关闭提示框：点右侧 × 试试
保存成功！你的修炼进度已记录。
心法提示：这一式需要动手敲，光看不练等于没学。
这条没有关闭按钮，会一直挂在页面上。

拆解一下：btn-close 是 Bootstrap 内置的 × 按钮；data-bs-dismiss="alert" 把它指向所在的提示框（点击即关闭，无需 JS）；aria-label="关闭" 让读屏用户知道这个 × 是干什么的。 提示框里放链接可以加 alert-link，颜色会自动跟随配色。

练功 · 第五式
  1. 给例 1 的色卡加一枚 btn-lg 的 primary 主按钮，并把“收件箱”按钮里的徽章改成 rounded-pill 胶囊形。
  2. 动手：做一个三键按钮组（预览 / 复制 / 下载），中间按钮里嵌一个胶囊徽章 99+，整组用 btn-group-lg。
  3. 思考题：链接式按钮（<a>）禁用时，为什么只加 disabled 类不够，还要 aria-disabled="true" 和 tabindex="-1"？
参考答案 1

徽章圆角由 rounded-pill 决定，与按钮圆角无关；徽章底色 text-bg-light 在朱砂主色按钮上很醒目。胶囊徽章适合“计数”，普通直角徽章适合“标签”。

参考答案 2

中间用实心 btn-primary、两侧用描边，主次一目了然；btn-group-lg 挂在组上，三个按钮一起变大，不必逐个写 btn-lg。

参考答案 3

disabled 类只管“看起来灰了”和“挡住鼠标点击”，但 <a> 没有 disabled 属性，键盘用户仍能 Tab 聚焦它、按回车触发跳转，屏幕阅读器 也不会播报“已禁用”。三件套各司其职：disabled 管样式与鼠标， aria-disabled="true" 让读屏宣告状态，tabindex="-1" 把它移出 Tab 顺序挡开键盘。缺一件，禁用就不完整。

本式小结

  • 按钮 = btn 本体 + 配色类，8 色各有语义，页面里实心主按钮一枚为宜；
  • btn-outline-* 描边、btn-lg/btn-sm 尺寸、disabled 与 active（配 aria-pressed）状态；
  • 链接式按钮禁用要三件套：disabled + aria-disabled="true" + tabindex="-1"；
  • btn-group 拼按钮组（配 role="group"），badge 嵌按钮 / 标题，rounded-pill 做胶囊计数；
  • alert 消息横幅必带 role="alert"；可关闭版 = alert-dismissible + btn-close + data-bs-dismiss="alert"。
