跳到正文

招式学到这里，已经不少。可真正的高手，懂得在不同的对手面前使出不同的招式—— 手机窄如短刃，桌面宽如长剑。这一式不教新组件，只传心法：如何让同一套页面，处处合身。

本式要点
  • 理解“移动优先”的思路：先写手机版，再用断点逐级增强
  • 记住五大断点（sm / md / lg / xl / xxl）与类名前缀的对应
  • 会用 d-none、d-md-block 等显隐工具类
  • 掌握“栅格断点 + 工具类”的组合套路
  • 补上 d-flex 家族的弹性工具类（前面几式演示的常客）

移动优先的思路

所谓移动优先，不是“只做手机版”，而是先写手机版，再逐步增强。 具体到 Bootstrap 的规则只有两条：

  • 不带断点前缀的类（如 col-12、d-none）是基础款，对所有宽度生效；
  • 带断点前缀的类（如 col-md-6、d-lg-none）只在该断点及以上生效， 它会覆盖同名的基础款。

为什么是“从小往大增强”，而不是反过来？因为手机的布局最简单——几乎永远是单列； 从小屏出发，每到一个断点只做加法（多分一列、多显一段），逻辑清爽。 反过来“从大往小裁剪”要做减法，容易顾此失彼。而且 Bootstrap 的断点一律用 min-width（“从这个宽度起”），天生就是为增强式写法准备的。

五大断点

Bootstrap 5.3.8 默认把屏幕宽度划成六档，其中后五档就是常说的“五大断点”：

断点类名中缀生效条件典型设备
xs（默认档）无前缀所有宽度手机竖屏
sm-sm-≥ 576px手机横屏
md-md-≥ 768px平板
lg-lg-≥ 992px小笔记本
xl-xl-≥ 1200px桌面显示器
xxl-xxl-≥ 1400px大屏显示器

记住规律：中缀就是断点名，写进任何响应式类里——col-md-6（md 起占 6 列）、 d-xl-none（xl 起隐藏）、p-lg-5（lg 起内边距 5 档）。 官方文档还允许自定义断点，但初学先把默认的记熟。

显隐工具类

响应式最常用的招式是“该出现时才出现”。核心只有两个类：

  • d-none——任何宽度都隐藏（display: none）；
  • d-断点-block——到该断点起显示（display: block）。

把两者组合起来，就是一对“开关”：

  • d-none d-md-block：md 以下隐藏、md 及以上显示——专给平板和桌面看；
  • d-md-none：md 以下显示、md 及以上隐藏——专给手机看。

注意：显隐工具类控制的是视觉显示，内容仍在 HTML 源码里， 只是不占位置、不显示。除 block 外还有 d-md-flex、 d-lg-inline 等变体，原理相同，按需要的 display 值取用即可。

container 各断点宽度

第二式讲过，container 是“会自动收窄的内容容器”。它的宽度不是固定的， 而是跟着断点走——屏幕越宽，上限越高：

屏幕宽度container 最大宽度
小于 576px100%（不设上限）
≥ 576px（sm）540px
≥ 768px（md）720px
≥ 992px（lg）960px
≥ 1200px（xl）1140px
≥ 1400px（xxl）1320px

也就是说，container 是“最大宽度”而非“固定宽度”：屏幕不够宽时按 100% 收缩， 足够宽时封顶，两侧留出呼吸空间。想永远铺满，用 container-fluid。

响应式组合套路

心法落到实战，通常是三招连用：

  • 栅格断点：col-12 col-md-6 col-xl-3——手机 1 列、平板 2 列、桌面 4 列；
  • 显隐切换：手机上给“汉堡菜单”按钮（d-md-none）， 桌面上铺开完整导航（d-none d-md-block）；
  • 间距字号随行：p-3 p-lg-5——手机留白小一点，桌面大方一点。
心法：响应式四诫
  • 先默认，再增强：基础款永远是手机版，断点只做加法；
  • 断点从低到高写：col-12 col-md-6 col-xl-3，顺序别乱，覆盖关系才清晰；
  • 每加一个断点先问自己：这个宽度下读者需要什么？不为断点而断点；
  • 调完必实测：拖动窗口缩放，亲眼看过才算数。

补遗：弹性工具类（前面演示里的常客）

从第四式起，演示里就常出现 d-flex、flex-wrap、 align-items-center、justify-content-between、gap-2 这些类名——它们是把 CSS 的 Flexbox 打包成的工具类，也是 Bootstrap 栅格系统的地基。 最常用的五个成员：

类名作用
d-flex / d-inline-flex开启弹性布局：子元素默认横向排开（块级 / 行内块级两种身份）
flex-wrap一行放不下时允许换行（不写则默认不换行、硬挤）
align-items-*横向排列时管“垂直对齐”：center 居中，start / end 顶 / 底
justify-content-*管“水平分布”，取值与第三式的行对齐完全同一套
gap-0–gap-5子项之间的固定间距，比给每个子项写 margin 省事

还有一位配角 ms-auto（自动左外边距）：在弹性行里常用来把某个元素“推”到最右边。 取值记不全没关系，工具类速查里有弹性布局专节。

例 3 · 弹性工具类五件套：一行头部，缩窄窗口看换行
品牌 目录 关于 右侧的按钮

五种类名各管一段：d-flex 让子元素并排、flex-wrap 允许换行、 align-items-center 把它们垂直居中、gap-2 拉开间距、 ms-auto 把最后一个元素推到最右。把窗口拖窄，“右侧的按钮”会掉到下一行—— 这就是它和栅格一样“跟屏幕走”的底气。

练功 · 第十五式
  1. 把例 2 里“md 及以上”的提示框改成“lg 及以上”才显示（提示：两处类名都要动）。
  2. 把例 1 的四个格子改成“手机 2 列、平板 2 列、桌面 4 列”（提示：基础款改成 col-6）。
  3. 思考题：为什么 Bootstrap 的断点用 min-width（“从这个宽度起”），而不是 max-width（“到这个宽度止”）？
参考答案 1

规律：把一对开关里的断点中缀一起换掉（-md- → -lg-）， 阈值就从 768px 挪到了 992px。两处不同步，就会出现“某段宽度两条同时显示或同时消失”的怪相。

参考答案 2

col-6 让手机上一行放两个格子，这条基础款会一直生效到 xl 之前， 所以平板自然也是两列；到 col-xl-3 再展开成四列。体会一下 “基础款管小屏、断点款管大屏”的分工——没有写到的档位，自动沿用更小一档的样式。

参考答案 3

因为 Bootstrap 奉行“移动优先、逐步增强”：基础样式（无前缀类）已经是完整的手机版， 断点只需要在更宽的屏幕上追加几条规则就行。用 min-width， 宽的规则天然写在后面、覆盖窄的规则，简单清晰。若用 max-width， 每加一档都要“反向裁剪”之前写好的桌面样式，规则互相打架，越写越乱—— 增强式写法是心法，min-width 只是它的自然结果。

本式小结

  • 移动优先 = 先写手机版，再用断点逐级增强，断点一律 min-width；
  • 五大断点：sm ≥576 / md ≥768 / lg ≥992 / xl ≥1200 / xxl ≥1400；
  • d-none d-md-block 表示“md 起显示”，d-md-none 表示“md 起隐藏”；
  • 弹性五件套：d-flex 开启、flex-wrap 换行、align-items-* 管垂直、justify-content-* 管水平、gap-* 管间距；ms-auto 推到最右；
  • 套路就三招：栅格断点分列、显隐类切内容、间距字号随行，最后缩放窗口实测。
