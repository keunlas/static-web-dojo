正篇走到最后一式，不再学新招式。今日的功课，是把前面学过的招式串成一套完整的剑法—— 导航、英雄区、卡片、栅格、图标，手写一个属于自己的作品集主页。

本式要点
  • 复习 navbar、hero、card、栅格、图标与显隐类的组合用法
  • 学会把多个组件组装成一个完整页面
  • 拿到一个完整成品的源码，作为后续练功的参考

成品先看

本式的成品是一个修行主题的作品集单页：作者假名“墨白”，六个假项目，全部用图标与色块代替图片， 响应式折叠导航，零外链、离线可用，只用本地 Bootstrap 与十几行点缀样式。

建议先在新标签打开完整成品：demo/portfolio/index.html。 缩放窗口、点点汉堡菜单，感受一遍，再回来看下面的逐节拆解。

动手拆解

整个页面按“从上到下、一块一节”的思路组装，一共六步。

第二步 · navbar 导航

导航用第九式学的 navbar。关键在 navbar-expand-lg： lg 以下收起为“汉堡”按钮，lg 及以上自动铺开——第十五式显隐心法的实战。 汉堡按钮与折叠区靠 data-bs-target="#navMenu" 对上暗号：

单页作品集里，导航链接用 #hero、#projects 这样的锚点就够了； ms-auto 把菜单推到导航条右侧。

两个细节：g-4 管卡片之间的间距；h-100 让同一行卡片等高， 不至于长短参差。色块是 project-thumb 加上一个换色类（project-a）， 大图标居中——没有一张图片文件，页面照样有“作品封面”的样子。

组装心法

心法：整页组装四要诀
  • 先骨架，后填充：五个 section 依次排开，每块独立成型，再逐块打磨；
  • 响应式只在两处动刀：导航的 navbar-expand-lg 与项目网格的 row-cols，其余布局天然自适应；
  • 图标与色块代替图片：页面零外链、零图片依赖，离线照样完整；
  • 不写一行手写 JavaScript：折叠菜单靠 data-bs-* 属性自动生效，bundle 脚本只是按需加载。

至此，Bootstrap 篇的正篇十六式收官。建议把成品页面 的源码逐行读一遍——你会发现没有一行陌生的东西，全是一路练过的招式。 正篇之外还有两式补遗：第十七式《图片与媒体》、第十八式《类名命名规律》， 学完它们，这一回才算真正圆满。

练功 · 第十六式
  1. 把 hero 里的“看作品”按钮改成 btn-outline-primary，并给“关于我”按钮加一个 bi-person 图标。
  2. 把项目网格改成“手机 1 列、桌面 3 列”，中间不再分两列（提示：只留两个 row-cols）。
  3. 思考题：为什么成品导航用 navbar-expand-lg，而不是 navbar-expand-md 或干脆不折叠？
参考答案 1

虚实搭配讲究主次：两个按钮都描边之后，“看作品”不再突出。 更常见的做法是保留“看作品”为实心 btn-primary（主行动）， “关于我”用描边（次行动）——虚实相生，页面才有层次。

参考答案 2

只把网格那行的类名 row-cols-1 row-cols-md-2 row-cols-lg-3 g-4 改成 row-cols-1 row-cols-lg-3 g-4——去掉中间的 row-cols-md-2，六张卡片一字不动（完整代码见上文第四步，把该行替换即可）：

md 档于是继承基础款 1 列，直到 lg 才展开成 3 列。想想这条规则—— 断点类只在“该断点及以上”生效，没有写到的档位，自动沿用更小一档的样式。

参考答案 3

这是断点选择的权衡：本页只有三个菜单项，就算在平板（md）上铺开也不会挤， 但收进汉堡同样无碍；选 lg 是让“小屏感”延续得更久一些—— 平板和手机都享受简洁的汉堡交互，桌面才铺开完整导航。 若菜单项很多（比如六个以上），平板就装不下了，那时应该改成 navbar-expand-md 提前铺开。可见断点没有标准答案， 判断标准只有一条：这个宽度下，内容放得下、用起来顺手吗？

本式小结

  • 整页组装 = 骨架 + 导航 + 英雄区 + 卡片网格 + 两栏介绍 + 页脚，逐块推进；
  • 响应式只靠 navbar-expand-lg 与 row-cols-* 两处完成；
  • 图标 + 色块代替图片，纯静态、零外链，离线可用；
  • 完整源码在 demo/portfolio/index.html，可对照拆解、任意改造。
