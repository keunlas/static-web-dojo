庭院深深，靠回廊引路；网页重重，靠导航指路。这一式，我们把给访客领路的家伙事 一次配齐：页签、胶囊、导航栏，还有那条标着“你来时的路”的面包屑。

本式要点
  • nav、nav-item 与 nav-link 的基础搭配
  • 会写 tabs 与 pills 的页签切换（data-bs-toggle）
  • 会搭响应式导航栏（含折叠汉堡按钮）
  • 认识 sticky-top 与 breadcrumb

nav 与页签

导航的最小单位是 nav：ul 挂 nav， 每个 li 挂 nav-item，里面的 a 挂 nav-link——默认就横排成一串。加上 nav-tabs， 就变成熟悉的页签外观；再让每个链接写 data-bs-toggle="tab" 并指向 tab-content 里对应 tab-pane 的 id，点击即切换。 全程不用写一行 JavaScript——这是 Bootstrap 的 data API 在自动生效，第一式就见过它的把戏。

把接线关系看明白，页签就不神秘了：

  • data-bs-target 里的 id，必须与某个 tab-pane 的 id 逐字对上；
  • active 决定初始显示哪一页（不写则一页都不亮）；
  • fade 让切换带渐隐，第一页还要多写 show；
  • 那一串 role/aria-* 是给读屏器的路标，跟着写即可。

胶囊与铺满

把 nav-tabs 换成 nav-pills，页签就变成胶囊按钮， 切换写法也随之改为 data-bs-toggle="pill"（同一个 tab 组件， 两个开关都认）。想让导航铺满整行，还有两个修饰类： nav-fill 按内容比例分摊宽度，nav-justified 则人人等宽。

导航栏的结构

页签管“一页之内”的切换，导航栏管“页面之间”的往来。一条完整导航栏有六件套：

  • navbar 定身份，navbar-expand-lg 定折叠时机——lg 断点（≥992px）以上横排展开，以下收起；
  • navbar-toggler 是汉堡按钮，data-bs-toggle="collapse" + data-bs-target 指向要折叠的那块；
  • collapse navbar-collapse 就是收起来的那块——id 必须与 toggler 的 target 对上；
  • navbar-brand 是门牌名号；菜单用 navbar-nav + nav-item + nav-link；
  • container-fluid 把内容兜住、左右留边。

上面那条面包屑（breadcrumb）也一并送上：ol 挂 breadcrumb，每级 li 挂 breadcrumb-item， 最后一格写 active 并标 aria-current="page"。 现在把浏览器窗口缩窄，看汉堡按钮现身、菜单收起。

配色与吸顶

默认导航栏是浅色；深底导航栏，在 navbar 上加 data-bs-theme="dark" 再配一个 bg-dark（或 bg-primary）即可，文字与汉堡图标会自动反白。注意：老教程里的 navbar-dark 写法在 5.3 已弃用，认准 data-bs-theme。

想让导航栏随页面滚动吸在顶上，加一个 sticky-top： 它只在滚动越过它时才钉住，不遮挡上方内容。它的兄弟 fixed-top 则从 一开始就钉在窗口顶部，需要给正文留出等高的 padding 才不挡字——日常用 sticky-top 更省心。

练功 · 第九式
  1. 把例 3 的导航栏改成深色版：加 data-bs-theme="dark"，并把 bg-body-tertiary 换成 bg-dark，观察文字与汉堡按钮的变化。
  2. 把例 1 的页签改成胶囊版：nav-tabs 换 nav-pills，所有 data-bs-toggle="tab" 换成 data-bs-toggle="pill"，再试切换。
  3. 思考题：导航栏的折叠按钮用的是 collapse 组件，页签用的是 tab 组件，为什么同一句 data-bs-toggle 要分两种写法？它们的分工有何不同？
参考答案 1

data-bs-theme="dark" 把导航栏切换进暗色模式，链接、品牌字、 汉堡按钮的描边与三道杠都会自动换成浅色；bg-dark 补上深色底。 只换 bg-dark 不换 theme，文字会“墨字沉在墨夜里”，什么都看不清。 改动只发生在 navbar 这一个标签上，面包屑部分无需动。

参考答案 2

tab-pane 那半边完全不用动——切换的“管线”不变，变的只是开关写法 与外观类名。这也是 Bootstrap 组件化的甜头：结构稳定，样式随意换。

参考答案 3

data-bs-toggle 后面的值，是告诉 Bootstrap “去启动哪个组件”： collapse 启动折叠组件，tab 启动页签组件。 两者的分工不同：collapse 只管自己——把一大块内容 收起或展开（导航栏菜单、第十一式的折叠面板都是它）；tab 则要联动—— 点亮自己被点的页签，同时切走别处的内容面板。所以导航栏的汉堡按钮借 collapse， 页签借 tab，各找各的搭档。至于 navbar-expand-lg 里的 lg， 就是第二式讲过的断点：屏幕宽于 992px 时菜单常驻横排，窄于此才需要汉堡按钮。

本式小结

  • nav/nav-item/nav-link 是导航的最小骨架，nav-tabs/nav-pills 换外观；
  • 页签切换靠 data-bs-toggle="tab"|"pill" + tab-content/tab-pane，全程零 JS；
  • 导航栏六件套：navbar-expand-* 定断点、toggler 按开关、collapse 藏菜单、brand 挂牌匾；
  • 深色用 data-bs-theme="dark"，吸顶用 sticky-top，面包屑是 breadcrumb 三件套。
