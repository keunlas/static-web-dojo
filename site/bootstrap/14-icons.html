bootstrap-icons 是什么

Bootstrap Icons 是 Bootstrap 官方出品的免费开源图标库（MIT 协议，商用无碍）， 收录了 2000 多个矢量图标，本站随附的是 1.13.1 版。 首页、按钮、表单、文件类型、品牌 Logo……日常写网页用得上的图标，它几乎全包了。

它的实现原理很妙：每个图标其实是一个字体字符。引入图标库之后，图标就跟着文字走——

  • 文字多大，图标就多大（font-size 说了算）；
  • 文字什么颜色，图标就什么颜色（color 说了算）；
  • 矢量图标任意缩放都不发虚，而且整套才几个 KB。

所以你不需要为图标准备什么“图片文件”，只要记住类名，图标就能随时长在文字中间。

注意一个新手最容易踩的坑：fonts 文件夹必须和 CSS 一起复制。 打开 bootstrap-icons.min.css，开头就能看到一行 src: url("fonts/bootstrap-icons.woff2")…——图标字库就放在 libs/fonts/ 里。只拷 CSS 不拷 fonts，图标会全部变成小方块。

本站的图标库放在 ../assets/vendor/bootstrap-icons/（CSS 与 fonts 相邻存放）， 并且已经由 loader 全站加载好了——所以本页的演示里你可以直接使用图标，不必再单独引入。

用法

用法一句话：给 <i> 元素加两个类——bi 定身份， bi-图标名 定长相：

几个小规矩：

  • 绝大多数图标都有空心 / 实心两个版本，实心版在类名末尾加 -fill：bi-heart 是空心，bi-heart-fill 是实心；
  • 图标默认贴着基线显示，要居中好看，可以给 bi 所在元素加 d-inline-flex align-items-center，或干脆用按钮、导航这类自带对齐的组件；
  • 图标是装饰，不是文字内容：建议加上 aria-hidden="true"，让屏幕阅读器跳过它； 纯图标的按钮则要给看不见的文字（见例 1 里的 visually-hidden）。

参考答案 1

只需把按钮里的类名改掉：<i class="bi bi-star-fill me-1" aria-hidden="true"></i>搜索。 图标立刻从放大镜变成实心五角星，按钮其余部分纹丝不动——这就是“改类名换长相”的便利。

参考答案 2

fs-1 把它放大到 2.5rem，text-danger 上色。 你也可以试试换 text-primary 或 text-success，感受“颜色跟随字体”的心法。

参考答案 3

图标并不是图片，而是字体里的字符。bootstrap-icons.min.css 开头的 @font-face 声明，把“字符编码 → 图标形状”的对应关系指到了 fonts/ 下的 bootstrap-icons.woff2 等字体文件上。 CSS 在而字体文件不在，浏览器就加载不到字形，只能画出一个个“缺字”的小方块。 所以拷贝图标库时，CSS 与 fonts 文件夹要成双入对。

本式小结

  • Bootstrap Icons 是官方出品的 2000+ 免费图标库，本站随附 1.13.1 版；
  • 引入只需一个 CSS，但 fonts 文件夹必须一起复制；
  • 用法是 bi + bi-图标名，大小看 font-size，颜色看 color；
  • 装饰性图标加 aria-hidden="true"，纯图标按钮加 visually-hidden 文字。
