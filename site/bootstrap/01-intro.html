Bootstrap 是什么

Bootstrap 是一套开源的前端组件库，最初由 Twitter 的工程师打造， 现在是 GitHub 上星标最多的开源项目之一。本教程使用它的最新稳定版 5.3.8。

它把写网页最常用、最重复的工作，封装成了拿来就用的类名，主要包括：

  • 一套响应式栅格系统——不用自己写 Flex/Grid，也能排出整齐的多栏布局（第二、三式专讲）；
  • 一大筐现成组件——按钮、表单、卡片、导航、模态框、轮播……几乎覆盖日常页面的全部需要；
  • 一套统一的视觉基础——字号、间距、颜色都有默认值，页面天生整齐耐看。

你只需要在 HTML 里给元素加上对应的 class（类名），比如给按钮写 class="btn btn-primary"，一个像模像样的按钮就出现了。

心法：Bootstrap 5 不依赖 jQuery

老版本（Bootstrap 4 及以前）需要先引入 jQuery 才能用它的交互组件； 从 Bootstrap 5 开始，它改用原生 JavaScript 重写，不再依赖 jQuery。 第三回的 jQuery 是另一套独立的工具，两者可以同台，但互不需要。

引入本地文件

Bootstrap 分为两个部分，都要引入：

  • 样式：bootstrap.min.css，放在 <head> 里；
  • 脚本：bootstrap.bundle.min.js，放在 </body> 之前。

“bundle”意为“捆绑包”——它已经内置了弹出层、下拉菜单等组件依赖的 Popper 定位库，初学者用 bundle 版一步到位，不必再单独引入。

两个细节值得记住：

  • 为什么脚本放在 body 末尾？因为脚本要操作页面元素，必须先等元素解析出来；放在末尾最稳妥。
  • 那个 meta viewport 是什么？它告诉手机浏览器按真实宽度渲染页面，是响应式设计的第一块基石，几乎每个页面都要写。

顺带一提：本教程网站自己就运行在 Bootstrap 上。你查看本站任意页面的源码会发现， 我们只用了一行 <script src="../assets/js/loader.js"></script> 就引入了 Bootstrap、图标库和本站皮肤——那是我们用十几行 JavaScript 写的一个小加载器， 等你在第三回学会 jQuery 后，回头再看它的源码会心一笑。

这里的每个类名都是 Bootstrap 的招式：

  • container——内容容器，让内容居中并留出两侧呼吸空间（第二式详讲）；
  • display-6——一种更大、更轻的大标题样式；
  • lead——稍大一号的引导段落；
  • btn btn-primary——按钮本体 + 主题色；
  • alert alert-primary——提示框本体 + 主题色；
  • mt-3——margin-top（上外边距）为 3 档，用来拉开距离；mb-0 则把下外边距清零。

浏览器是按顺序解析页面的：放在 <head> 里的脚本执行时，页面正文还没被解析出来， 脚本里如果去“找元素”就会扑空。放在 </body> 之前，则执行时正文元素都已就绪。 第三回学 jQuery 时，你会见到另一种解法：$(document).ready——它能让脚本“等页面就绪再动手”。

本式小结

  • Bootstrap 是一套开源前端组件库，本教程使用 5.3.8；
  • 样式放 <head>，脚本放 </body> 前，bundle 版一步到位；
  • 它的核心玩法就是“给元素加类名”，第二式起，我们正式开始学招式。
