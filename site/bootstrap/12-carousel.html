招式学到这里，剩下几件“小兵器”虽不起眼，却常伴左右：轮播、进度条、分页、加载动画。 本式一并授你——都是几行类名的事。

本式要点
  • 掌握 carousel 的完整结构：内层轨道、页面项、控制按钮、指示器、说明文字
  • 会配 data-bs-ride="carousel" 自动播放与 data-bs-interval 播放间隔
  • progress 进度条：数值宽度与多段组合
  • pagination 分页（active / disabled）与 spinner 加载动画

轮播 carousel：会自己翻页的展台

轮播（carousel）是一个循环播放的幻灯片展台：一页页内容定时轮转， 访客也可以手动前后翻。它的结构件件有名有姓：

  • 外层 carousel slide——展台本体，data-bs-ride="carousel" 让它在页面加载后自动开播；
  • carousel-inner——内层轨道，里面放 carousel-item，第一页必须加 active；
  • carousel-control-prev / carousel-control-next——左右控制按钮， 带 data-bs-target="#展台id" 与 data-bs-slide="prev|next"；
  • carousel-indicators——底部指示器，每个按钮带 data-bs-slide-to="页号"；
  • carousel-caption——每页底部的说明文字。

自动播放的间隔由 data-bs-interval 指定，单位毫秒——3000 就是 3 秒翻一页。

心法：轮播不一定要图片

carousel-item 里放什么都可以——图片、卡片、甚至纯文字。 本站坚持零外链图片，所以演示用纯色背景块 + 图标 + 文字做“页”。 你把背景块换成自己的 <img>，就是货真价实的轮播图。

例 1 里每个 carousel-item 都指向同一个 #bs12-demo1—— 这是轮播的“中枢点名”：指示器、控制按钮、翻页动作全靠它对上号。 图标 bi bi-* 是 Bootstrap Icons 的写法，下一式之后我们专门修炼。

进度条 progress

进度条（progress）用来直观展示完成度。结构很简单： progress 是浅色的轨道，里面放一根 progress-bar 填充条， 宽度由行内样式 style="width: 70%" 决定。 条上还能直接写字——把文字放进 progress-bar 即可。

剑术修为 70%

一条轨道也可以装多段进度——用 progress-stacked 把多根 progress-bar 包起来，配不同的 bg-* 颜色，各段宽度加起来不超过 100% 即可。

分页 pagination

分页（pagination）给多页内容编号导航。结构是 pagination 列表里放 page-item，每项包一个 page-link； 当前页给 page-item 加 active，不可点的项加 disabled。 外层用 <nav aria-label="…"> 包裹，读屏软件才知道这是一组页码。

例 4 · 分页：当前页高亮，上一页禁用
  • 上一页
  • 1
  • 2
  • 3
  • 下一页

真实项目里，每个 page-link 的 href 指向对应页面的地址（如 list-2.html）；演示里用 #… 这类不存在的锚点占位，点击不会让页面跳走。

加载动画 spinner

加载动画（spinner）告诉访客“稍等，正在处理”。两种样式： spinner-border 转圈，spinner-grow 呼吸闪烁； 颜色随 text-*，尺寸用 spinner-border-sm 或行内 style="width:…;height:…"。它们是纯 CSS 动画，不消耗 JavaScript。 每个 spinner 都要配一句 visually-hidden 的状态说明，供屏幕阅读器朗读。

练功 · 第十二式
  1. 给例 1 的轮播加上第四页（提示：carousel-indicators 与 carousel-inner 里都要加）。
  2. 把例 2 的进度条改成条纹动画版：在 progress-bar 上追加 progress-bar-striped 与 progress-bar-animated 两个类。
  3. 思考题：分页为什么要用 <nav aria-label="…"> 包裹、spinner 为什么要配 visually-hidden 文字？这些“看不见”的东西是给谁用的？
参考答案 1

页号从 0 数起：第四页是 data-bs-slide-to="3"。新页不要加 active——一个轮播里只能有一个当前页，加了会打乱开播顺序。 把上面两段分别插进例 1 的 carousel-indicators 与 carousel-inner，就是完整的四页轮播。

参考答案 2

progress-bar-striped 画出斜向条纹，progress-bar-animated 让条纹流动起来——两者叠加，就是“正在加载”的经典样式，适合用在实时刷新的进度上。

参考答案 3

这些“看不见”的属性是给屏幕阅读器用的：视障用户靠朗读浏览网页， 一个光秃秃的转圈对他们来说什么都不是。所以：<nav aria-label> 让读屏软件把一列页码读成“藏经阁书目分页”，而不是一串莫名链接； visually-hidden 的文字视觉上隐藏、朗读时照读，补上“加载中”的状态说明。 看不见的讲究，恰恰是专业与业余的分水岭。

本式小结

  • 轮播五件套：carousel slide / carousel-inner / carousel-item active / 控制按钮 / 指示器；
  • data-bs-ride="carousel" 自动播放，data-bs-interval 定间隔，carousel-caption 配说明；
  • 进度条：progress 轨道 + progress-bar 填充，多段用 progress-stacked；
  • 分页 active / disabled，spinner 有 spinner-border 与 spinner-grow 两种样式。
