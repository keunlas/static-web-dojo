折叠 collapse：把内容折起来

折叠（collapse）是一块“可开合的内容面板”：平时整块收起（display:none）， 点一下触发器就展开。详情说明、设置面板、长文附录，都是它的用武之地。

触发器有两种写法，效果相同：

  • <button>——写 data-bs-toggle="collapse" 声明身份， data-bs-target="#id" 点名目标；
  • <a>——同样写 data-bs-toggle="collapse"，但目标由 href="#id" 指定。

目标面板则是一个带 collapse 类的元素，通常外面套一张 card，让内容有底有边。

一键开合多个目标

妙处来了：data-bs-target 接受的其实是一个 CSS 选择器，不只限一个 id。 给多个面板共享同一个 class，一个按钮就能让它们同开同合——比如一页多个详情同时展开。

手风琴 accordion：只开一扇门

手风琴（accordion）是折叠的进阶形态：一组面板互斥， 点开新的，旧的自动合上，永远只开一扇门。FAQ（常见问题）是它的经典场景—— 问题排成一条，点开哪个看哪个，页面始终清爽。

它的结构比普通折叠多一层包装，共五件：

  • accordion——手风琴容器；
  • accordion-item——每一项（一组问答）；
  • accordion-header + accordion-button——标题头与开关按钮；
  • accordion-collapse + accordion-body——可折叠的面板与正文。

“只开一扇门”的机关在 data-bs-parent="#手风琴id"： 每个面板都指向同一个手风琴容器，Bootstrap 据此把其他面板当作“同门”，开新必关旧。 默认展开的项，在 accordion-collapse 上加 show 类、 按钮上写 aria-expanded="true"。

无缝变体 accordion-flush

默认的手风琴每项之间有明显分隔与圆角。若想让它与父容器（比如一张卡片）无缝贴合， 给容器再加一个 accordion-flush 类——去掉外框与圆角，只保留项间的细线。

练功 · 第十一式
  1. 让例 1 的面板默认展开：给 collapse 面板加上 show 类， 并把两个触发器上的 aria-expanded 改为 "true"。
  2. 把例 3 三个 accordion-collapse 上的 data-bs-parent="#bs11-demo3" 全部删掉，再依次点开两项，观察“只开一扇门”是否失效。
  3. 思考题：为什么手风琴必须靠 data-bs-parent 指向同一个容器，而不能自动按 “同一个父元素”互斥？
参考答案 1

show 是 collapse 的“初始展开”标记；aria-expanded 则要与真实状态一致， 否则屏幕阅读器会误报。第一次点击之后，数据 API 会自动帮你同步 aria-expanded 与按钮上的 collapsed 类。

参考答案 2

删掉 data-bs-parent 后，依次点开两项，两项会同时展开—— “只开一扇门”就此失效。这正是手风琴与普通折叠的本质区别： 折叠面板本身互不相识，data-bs-parent 是它们之间的“师门名册”， 有了它才知道“开我时必须关谁”。

参考答案 3

因为“同一父元素”不等于“同一互斥组”。一个手风琴容器里可能嵌套着其他折叠面板 （比如某个答案里又有一个折叠详情），它们住在同一父元素下，却不想参与互斥； 反过来，DOM 结构也可能中途换包装。所以 Bootstrap 不猜关系，而是用 data-bs-parent 让你显式点名互斥范围—— 谁指向同一个容器，谁就是一家人。

本式小结

  • 折叠面板：触发器写 data-bs-toggle="collapse"，button 用 data-bs-target、a 用 href 点名；
  • data-bs-target 接受 CSS 选择器，一个按钮可以同开同合多个面板；
  • 手风琴五件套：accordion / accordion-item / accordion-header / accordion-collapse / accordion-body；
  • “只开一扇门”靠 data-bs-parent 圈定互斥范围；accordion-flush 让手风琴无缝贴边。
