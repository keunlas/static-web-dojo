跳到正文

十六式走完，架子、组件、心法都齐了，还剩一位常客没正式打过招呼——图片。 页面里迟早要放图，而图放不好，再漂亮的布局也会东倒西歪。这一式补上这一课。

本式要点
  • img-fluid：让大图自动缩到容器宽度，永不撑破页面
  • img-thumbnail 与 rounded 系：给图片加边框与圆角
  • figure / figcaption：图片配说明的标准写法
  • ratio 固定比例容器与 object-fit 裁切配合

响应式图片：img-fluid

一张原始尺寸 1200 像素宽的图，碰上只有 200 多像素宽的容器，默认会撑破容器， 在手机上更是直接顶出屏幕。给 <img> 加上 img-fluid， 它会翻译成两条规则：max-width: 100%（不许超过容器）与 height: auto（高度按比例跟着缩，不变形）。

心法：响应式页面里的图片默认都要 img-fluid

可以记成一句口诀：“图片若无 img-fluid，手机上准出洋相。” 容器靠栅格自适应，图片也必须有“不许超出”的谦逊——两者都谦逊，页面才稳。

缩略图与圆角

img-thumbnail 给图片配一圈细边、一点内边距和圆角，像相册里压好的照片： 省去手写边框样式。rounded 系工具类则由你自己控制圆角： rounded（小圆角）、rounded-3（更大）、 rounded-circle（正圆，配合 object-fit: cover 做头像）、 rounded-pill（胶囊形）。

图文混排：figure 与 figcaption

图片配一句说明，标准的写法是 figure 包图、figcaption 写说明。 Bootstrap 再给它们配上三个类：figure 是外框，figure-img 给图片留出与说明文字的间距，figure-caption 把说明文字调成小号灰字。 用语义化标签的好处是：读屏软件、搜索引擎都明白“这张图带着说明”， 而不只是“两段挨着的文字”。

例 3 · 带说明的图（figure）

若说明文字想居中，给 figcaption 加一个 text-center 即可； figure 也可以放进卡片、栅格列里，它本身只是一个语义容器。

固定比例容器：ratio 与 object-fit

响应式页面里最恼人的是“图片高度不定”：图没加载完，页面高度会跳；栅格里的图比例不一， 卡片高矮不齐。Bootstrap 的 ratio 用一个容器把位置先占好—— ratio-16x9、ratio-4x3、ratio-1x1 分别固定 16:9、4:3、1:1 的比例，里面的图片填满容器。

又因为比例是固定的，图片自己的比例往往对不上，这时就该 object-fit 出场： object-fit-cover 填满并裁掉多余部分（不变形，适合照片缩略图）， object-fit-contain 完整显示并且可能留白（不变形，适合图表与截图）。

例 4 · 同一张图，三种比例，两种裁法

ratio-16x9 + object-fit-cover

ratio-1x1 + object-fit-cover

ratio-4x3 + object-fit-contain

补充：ratio 里还能放什么

ratio 容器不挑内容：图片、iframe（比如内嵌地图）、 video 都可以放进去，容器会按固定比例给它们留好位置。 单独用 object-fit-* 时，记得让图片的宽高同时被约束 （如 h-100 w-100），不然它不知道自己该适配哪个框。

练功 · 第十七式
  1. 把例 1 右栏的图片改成“img-fluid + mx-auto 居中”，并让它不超过 260px 宽。
  2. 用 ratio-1x1 + object-fit-cover 做一个正方形的“头像块”，里面放例 4 的横幅图。
  3. 思考题：为什么 ratio 容器里的图片不必再写 img-fluid？
参考答案 1

img-fluid 负责“不许超出容器”，mx-auto 负责水平居中。 但 <img> 默认是行内元素，行内元素不认 mx-auto， 所以要补一个 d-block 把它变成块级元素——这对搭档在图片居中时几乎形影不离。

参考答案 2

ratio-1x1 把容器固定成正方形，object-fit-cover 让图片铺满这个正方形并裁掉多余部分——比例稳定、图片不变形， 是相册网格与头像的标准做法。

参考答案 3

因为 ratio 的内部规则是“子元素绝对定位、宽高都拉满 100%”， 图片的尺寸由容器说了算，天然不会超出容器，也就用不着 img-fluid 再补一道“不许超出”的限制。此时真正需要你决策的是另一件事： 图片比例与容器不一致时，是裁掉（cover）还是留白（contain）。

本式小结

  • 响应式页面里的图片统统加 img-fluid，它是防溢出的第一道保险；
  • img-thumbnail 一键出相册效果，rounded 系自己控制圆角；
  • 图配说明用 figure + figcaption（配 figure-img / figure-caption），语义清晰；
  • ratio 先占好位置，object-fit 决定图怎么填：cover 裁、contain 留白。
