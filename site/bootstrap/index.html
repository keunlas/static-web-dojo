Bootstrap 是江湖上流传最广的一套前端组件库。它把常用的布局与组件做成了一套 拿来即用的类名——栅格、按钮、表单、导航、模态框……信手拈来。

本回使用 Bootstrap 5.3.8，全部资源已放在本站本地，无需联网。 十八式由浅入深：前五式打好布局与内容的地基，中间十式攻克组件与交互， 第十六式把它们全部串起来、手写一个完整的作品集主页；第十七、十八式是补遗—— 图片与媒体、类名命名规律，把工具箱填满。

修炼建议

每一式都遵循“讲解 → 现场演示 → 看源码 → 练功”的节奏。 演示里每个例子都值得亲手敲一遍；卡住时，去藏经阁的离线文档查对应的组件说明。
