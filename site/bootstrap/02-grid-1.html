上一式只算亮了个相。从这一式起，我们修炼 Bootstrap 的看家本领——栅格系统。 江湖上人人都说布局难，其实拆开看，不过是一个容器、几行几列，把十二个格子分来分去罢了。

本式要点
  • 分清 container 与 container-fluid 两种容器
  • 会用 row 与 col 搭出十二列栅格
  • 理解断点前缀 sm / md / lg / xl / xxl 与“移动优先”的写法
  • 能写出手机堆叠、桌面并排的响应式布局

容器：container 与 container-fluid

栅格系统的第一层是容器。container 是“定宽居中”：内容居中， 两侧留出呼吸空间，宽度随屏幕档位有上限；container-fluid 是“通栏”： 永远撑满父元素的宽度，不留白。

屏幕档位container 的最大宽度
手机（<576px）100%（通栏）
sm（≥576px）540px
md（≥768px）720px
lg（≥992px）960px
xl（≥1200px）1140px
xxl（≥1400px）1320px

也就是说：屏幕上 container 会随宽度“跳档”变宽，直到 1320px 封顶。

例 1 · 两种容器对比（把浏览器窗口拉宽看差异）
container —— 定宽居中，两侧留白
container-fluid —— 通栏，撑满整个宽度

用哪个？正文页几乎都用 container；需要背景色横贯全屏的导航条、页脚， 通常外层 container-fluid、内层再套一个 container 让内容居中。

行与列：row 与 col

容器里先放行 row，行里放列 col。 Bootstrap 把每一行想象成 12 等份，col 后面的数字就是“占几份”： col-4 占 4 份（三分之一宽），col-6 占一半，col-12 占满。

心法：栅格三句话
  • 列必须放在行里，行最好放在容器里；
  • 一行里所有数字之和不要超过 12，超过了会换行；
  • 数字写的是占比不是像素，所以栅格永远跟得上屏幕宽度。

断点：让布局跟屏幕走

光有十二列还不能“响应式”。断点是 Bootstrap 预设的 5 档屏幕宽度门槛， 前缀写在 col 和数字之间——col-md-6 意为“从 md 起占 6 列”。

前缀生效门槛典型设备
无前缀所有宽度（基础款）手机竖屏起，逐级往上叠加
sm≥576px手机横屏、小平板
md≥768px平板
lg≥992px笔记本
xl≥1200px桌面显示器
xxl≥1400px宽屏大屏
心法：移动优先

无前缀的规则对所有屏幕生效，带前缀的只在对应档位起叠加覆盖。 所以写法永远是“先手机、再往上加”：col-12 col-md-6 意为手机占满 12 列堆叠， md 起覆盖成占 6 列并排。顺序别反着来——先写大屏再写小屏，等于让自己多打一场补丁仗。

把浏览器窗口拖过 768px 那条线，三栏就在“堆叠 / 并排”之间切换——这就是响应式最常用的一个动作。 注意看类名：手机样式 col-12 在前，桌面样式 col-md-4 在后，桌面覆盖手机。

例 6 · 3:9 侧边栏布局预告：侧栏 3 份 + 内容 9 份
侧边栏（3 份）
手机堆叠在上方
内容区（9 份）
3 + 9 = 12，正好一行

这是网页最常见的骨架之一。下一式会把它做成完整套路——内容区 + 侧边栏的 9:3 布局， 外加嵌套、偏移与对齐，让侧栏想站哪边就站哪边。

练功 · 第二式
  1. 把例 5 的三栏改成四栏：每个列该换成什么类？写出完整代码。
  2. 动手做一个“左 8 右 4”的两栏布局：左边放一段介绍文字，右边放一张图片占位块。
  3. 思考题：col-md-6 里只有一个断点规则，为什么在手机上它会自动占满整行，而不是挤成半行？
参考答案 1

12 份平分给 4 栏，每栏 3 份，所以把 col-md-4 全换成 col-md-3：

手机上依然堆叠（col-12 不变），桌面变四栏。3 + 3 + 3 + 3 = 12，正好一行。

参考答案 2

8 + 4 = 12。手机上文字先出现、图片后出现，桌面并排——顺序完全由 HTML 里写的前后决定。

参考答案 3

Bootstrap 给 row 的所有直接子元素设了一条兜底规则：没有生效的列宽时，默认占满 100% 宽。 col-md-6 的“占 6 列”只在 ≥768px 时生效；手机上这条规则不存在，兜底规则接管， 于是每列占满整行、自动堆叠。这正是“移动优先”的底气：小屏永远有得体默认值，大屏样式只是往上加。

本式小结

  • 容器：container 定宽居中（最大 540 / 720 / 960 / 1140 / 1320px），container-fluid 通栏；
  • 行 row + 列 col-N：一行 12 等份，数字是占比不是像素；
  • col 不带数字 = 自动均分；
  • 断点前缀 sm / md / lg / xl / xxl，移动优先：先写手机，再往上加。
