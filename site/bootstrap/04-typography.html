架子搭好了，接下来给页面添血肉。这一式没有大组件，全是一招一式的小工具类—— 但它们用得最勤，一招鲜，吃遍天。

本式要点
  • display-1 到 display-6 六档大标题与 lead 引导段
  • 文本处理：mark、small、list-unstyled、list-inline 与对齐
  • 8 色系：text-*、bg-* 与 text-bg-* 组合
  • border、rounded、shadow 与间距工具类 p-* / m-*

标题与引导段

Bootstrap 把字号排成体系。display-1 到 display-6 是六档“展示型大标题”， 字号从 5rem 一路递减到 2.5rem，字重更轻（300），适合首页横幅；正文内部的分层用普通 h1–h6 标签即可（本章页的各级小标题就是例子）。 lead 是“引导段”：比正文大一号，适合放在页首领衔。

文本处理：标记、小字与列表

mark 是黄底高亮；small 是小一号的弱化文字，适合备注与版权行； list-unstyled 去掉列表默认的项目符号和缩进；list-inline 把竖排列表变成横排 （每个 li 上配 list-inline-item）。对齐有 text-start / text-center / text-end 三档。

顺带一提：Bootstrap 5 把旧版的 text-left/right、ml/mr 换成了 text-start/end、ms/me——为的是支持从右向左的语言（练功第 3 题细说）。

颜色：text-* 与 bg-*

Bootstrap 有一套贯穿全站的 8 色系：primary（主色）、 secondary（次色）、success（成功绿）、danger（危险红）、 warning（警示黄）、info（信息青）、light（浅）、 dark（深）。文字色用 text-*，背景色用 bg-*， 还有 text-bg-* 一次同时搞定背景和对比文字色。

心法：本站把 primary 染成了朱砂

本教程网站的皮肤把 primary 定义成了朱砂色，所以本页的 text-primary、 bg-primary 都是朱砂而不是原版蓝。这正是“主题定制”的活例子，原理留到第十五式。

边框、圆角与阴影

border 加一圈细边框，border-primary 等可以给边框上色； rounded 是小圆角，rounded-3 更大，rounded-pill 是胶囊形、 rounded-circle 是圆形；阴影三档：shadow-sm / shadow / shadow-lg，由浅入深。

间距工具类：p-* 与 m-*

留白靠两大家族：p-*（padding 内边距）与 m-*（margin 外边距）。 数字 0–5 共六档：0 是零、1 是 0.25rem、2 是 0.5rem、3 是 1rem、4 是 1.5rem、5 是 3rem； m-* 另有 auto（自动分配剩余空间）。方向后缀：t 上、 b 下、s 左、e 右、x 左右、y 上下； 不带后缀就是四边一起。于是有了 mt-3（上外边距 1rem）、pe-2（右内边距 0.5rem）、 mx-auto（左右自动外边距，让定宽块水平居中）。

练功 · 第四式
  1. 把例 5 的名片改成浅色版：白底细边框（bg-light + border）、深色字（text-dark）、主色点缀（text-primary）。
  2. 动手：用 list-inline 做一行页脚链接，三个链接之间留出间距。
  3. 思考题：为什么 Bootstrap 5 把 text-left/right 改成 text-start/end、把 ml/mr 改成 ms/me？
参考答案 1

浅底上不必再写 text-white（默认正文色就是深色）；分隔线的 border-light 在浅底上太浅，去掉即可。本站的 text-primary 是朱砂色，与浅纸底很配。

参考答案 2

list-inline-item 自带右侧间距，三个链接自然分开；链接样式全站由皮肤接管。

参考答案 3

因为 start/end 是“逻辑方向”：在从左向右的语言（中文、英文）里 start 就是左， 在从右向左的语言（阿拉伯语、希伯来语）里 start 自动变成右。用逻辑方向写一遍类名， 两种文字方向都能正确呈现，无需为 RTL 语言另写一套样式——这是国际化网页的基本素养。

颜色与边框的补遗

八色系还有几个“深浅变体”和“专用出口”：bg-*-subtle 是柔和浅底， text-*-emphasis 是加深的文字色，两者搭配最不容易翻车； link-* 专门管链接颜色；opacity-* 控制整块元素的透明度； 边框还有粗细档与“只留一边 / 去掉一边”的写法。

本式小结

  • 大标题 display-1 到 display-6（5rem 递减到 2.5rem），引导段 lead；
  • 文本处理：mark 高亮、small 弱化、list-unstyled 去符号、list-inline 横排；
  • 8 色系 text-* / bg-* / text-bg-*，深底记得配 text-white；
  • border / rounded(-pill/-circle) / shadow(-sm/-lg) 三件套；
  • 间距 p-* / m-*：数字 0–5 六档 + auto，方向后缀 t / b / s / e / x / y。
