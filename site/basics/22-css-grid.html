Flex 排一行，Grid 排一张表。 上一式的弹性布局管的是“一条线上的分配”，这一式的网格布局管的是 “横竖同时要对齐”的场面——整页骨架、相册、仪表盘都归它管。

本式要点
  • 理解网格的三件套：网格线、轨道、单元格，分得清显式网格与隐式网格
  • 会用 fr、repeat()、minmax()、auto-fit 写会自适应的列
  • 会让项目跨格（span / 坐标 / grid-area）或用模板区域排整页
  • 会用对齐属性与“同一格叠加”，知道 Grid 与 Flex 各自的主场

心智模型：线、轨道、单元格

声明 display: grid 之后，容器就变成一张网格。理解它只需要三样东西：

  • 网格线（line）：划分网格的每一条线，从 1 开始编号， 负数则从末尾数（-1 是最后一条线）；
  • 轨道（track）：两条线之间的行或列，也就是“一行”“一列”；
  • 单元格（cell）：行与列交叉出的一格，是项目最自然的落点。

还有一对概念值得先分清：你在 grid-template-* 里写出来的叫 显式网格；项目多出来、容器自动补出的行列叫隐式网格， 它的尺寸由 grid-auto-rows / grid-auto-columns 决定 （不写的话按内容高度自适应）。

三个格子一行是“自动”的：写完 grid-template-columns， 浏览器就把项目按顺序从左到右、从上到下填进去（这叫自动流，由 grid-auto-flow 控制）。所以 Grid 的第一印象应该是： 先搭框架，再往里放东西。

列宽怎么写：fr、repeat、minmax、auto-fit

写法 含义 典型用途
1fr 1fr 1fr fr 是“剩余空间的一份”，三份就是三等分 等宽列
repeat(3, 1fr) 重复三次，等价于上面那种写法 列数固定但不想数格子
200px 1fr 第一列固定 200px，第二列吃掉剩下的 固定侧栏 + 自适应主栏
minmax(200px, 1fr) 最小 200px、最大 1fr，在区间里伸缩 配合 auto-fit 写“自动换列”的卡片墙
repeat(auto-fit, minmax(200px, 1fr)) 能塞几列塞几列，每列不小于 200px 最常用的自适应写法（不写媒体查询）
repeat(auto-fill, …) 同 auto-fit，但会保留空轨道占位 想让卡片列数固定、留白时用

一个容易踩的点：1fr 的最小值默认是 auto—— 意思是“不能比内容还窄”。遇到长内容同样会撑破布局（和第二十一式的 min-width: auto 是同一个家族的问题）， 这时写成 minmax(0, 1fr) 就能治好。

放哪一格、跨几格

项目默认按顺序自动落位，但你完全可以手动指定。两种写法都很常用：

写法 含义
grid-column: 1 / 3从第 1 条竖线跨到第 3 条竖线（占两列）
grid-column: 2 / -1从第 2 条线一直到最右边那条线
grid-column: span 2不关心起点，向后占两列
grid-row: 1 / 3纵向跨两行（做竖排侧栏常用）
grid-area: 3 / 3简写：行起 / 列起（也可以写全四个值）
grid-area: header直接用命名区域（配合 grid-template-areas）
例 3 · 跨格：标题跨三列、侧栏跨两行、还有一格被显式点名
标题（span 3，横跨三列）
侧栏（row span 2，竖跨两行）
普通格子
普通格子
普通格子
我用 grid-area: 3 / 3 点名站位

注意“跟着队伍走”与“点名站位”的区别：span 是“我占两格，队伍继续排”， grid-area: 3 / 3 是“我就在第三行第三列，谁也别管”。 混用时要有心理准备：被点名的项目会先占好位置， 其余项目再按顺序填剩下的空格（必要时会被挤到后面的隐式行里）。

模板区域：把骨架画成一行行文字

grid-template-areas 是 Grid 最讨人喜欢的地方： 你能用 ASCII 画图的方式描述整页布局，再把项目“分配”给区域名。

例 4 · 用模板区域排一个完整页面骨架
页头 header
侧栏 aside
正文 main（占最大的一块）
页脚 footer

模板区域里用 . 表示那一格留空，同一个名字连着写就表示跨格。 它最大的好处是改布局只需重画那张图： 把 "side main" 改成 "main side"，侧栏就跑到右边； 加一句媒体查询（第二十三式）就能在窄屏把它变成单列。

对齐与叠加：格子里怎么放、能不能叠

Grid 的对齐属性分三层，名字都是 justify-（横轴）与 align-（竖轴）：

层级 属性 管什么
单元格内部 justify-items / align-items（简写 place-items） 每个项目在自己格子里的位置（默认 stretch，拉满格子）
单个项目 justify-self / align-self（简写 place-self） 只改这一个项目的对齐
整张网格 justify-content / align-content（简写 place-content） 网格整体比容器小时，整体往哪摆（轨道用了 1fr 时就无事可做）

观察要点：窗口变窄到放不下两列时，会自动变成一列； 变宽时列数增加，但每列都不会小于 180px。 想固定列数（例如始终四列，不足时留空）就把 auto-fit 换成 auto-fill，或直接写 repeat(4, 1fr) 配合媒体查询。

参考答案 2

只需要改“那张图”（以及列的宽度顺序），项目上的 grid-area 完全不用动—— 这正是模板区域的价值：布局的变化集中在容器一处。

参考答案 3

一行卡片：卡片数量不定、每张宽度由剩余空间分配——这是典型的一维分配， 用 display: flex + gap + flex: 1 1 220px 最直接； 或者用 Grid 的 repeat(auto-fit, minmax(220px, 1fr))， 两者都能做，看团队习惯。 整页骨架：页头、侧栏、正文、页脚需要横竖同时对齐， 而且“谁在哪一格”是设计决定而不是内容决定——这正是 Grid 的主场， 用 grid-template-areas 一眼就能看懂整张版式。 一句话：内容决定排布用 Flex，版式决定位置用 Grid。
