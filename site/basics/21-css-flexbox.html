到了这一式，才算真正摸到现代布局的门槛。 Flexbox 用一句话说清它的野心：让“一排东西怎么摆”这件事，变成几个开关—— 居中不用猜、等高不用凑、间距不用算。

本式要点
  • 理解主轴与交叉轴，知道轴的方向由 flex-direction 决定
  • 掌握容器六件事：flex-direction、flex-wrap、 justify-content、align-items、align-content、gap
  • 掌握项目四件事：flex-grow/shrink/basis（含 flex 简写）、 order、align-self、min-width 陷阱
  • 能凭手感写出居中、导航栏、等高卡片、固定 + 自适应两栏、页脚吸底

心智模型：容器、项目、两条轴

用了 display: flex 的元素叫弹性容器， 它的直接子元素自动变成弹性项目。 容器里会出现两条轴：

  • 主轴：项目默认排列的方向。默认是“横着、从左到右”；
  • 交叉轴：与主轴垂直的那条。默认是“竖着、从上到下”。

所有对齐属性都是按这两条轴命名的，所以第一件要记住的事是： flex-direction 一改，主轴和交叉轴就跟着换—— justify-content 与 align-items 的作用方向也随之对调。

属性 含义 要点

常见套路：五个能直接抄的组合

想要的效果 写法
水平垂直居中 display: flex; align-items: center; justify-content: center;
导航栏（左边品牌、右边菜单） display: flex; align-items: center; gap: 1rem; + 菜单上加 margin-left: auto（或容器 justify-content: space-between）

一个必须知道的坑：flex 项目不肯缩

弹性项目的 min-width 默认是 auto，意思是 “不许缩到比内容还窄”。平时这是保护，遇到一长串不可断开的内容 （长校验码、长单词、连成一串的代码）就变成麻烦——它宁可顶破容器也不肯缩。 解决办法是显式写 min-width: 0，再配省略号收尾。 这里还有个反直觉的细节：普通网址里带斜杠与连字符，浏览器可以在这类位置断开， 所以它常常不触发这个坑；真正撑破布局的，多半是那些“没有任何断点”的字符串。

对照着看就明白了：第一行那句网址直接撑破了虚线框（宽度比容器还大）， 第二行被老老实实收在框内并显示了省略号。 还要留意一个容易忽略的细节：给项目加了 overflow: hidden 之后， 它的 min-width: auto 保护就自动失效了—— 也就是说，“裁切类”的样式本身就会解除这条保护。 所以口诀可以记成：弹性项目 + 省略号 = overflow: hidden + min-width: 0， 两者一起写，任何浏览器都不会给你惊喜。

什么时候用 Flex，什么时候用 Grid

  • 一维（一行或一列）用 Flex：导航栏、按钮组、卡片行、居中；
  • 二维（行列同时要控制）用 Grid：整页骨架、相册、仪表盘；
  • 两者可以嵌套：Grid 排大区块，每个区块内部用 Flex 排细节；
  • 还有一条经验：“内容决定布局”用 Flex，“布局决定内容位置”用 Grid。

本式小结

  • display: flex 让直接子元素成为弹性项目；主轴由 flex-direction 决定；
  • 主轴用 justify-content，交叉轴用 align-items，多行之间用 align-content；
  • gap 管间距，比算 margin 省心；
  • 项目四件事：flex 系列管伸缩（flex: 1 ＝ 1 1 0%）、 order 管视觉顺序（慎用）、align-self 单独对齐、min-width: 0 解溢出；
  • 五套常用组合：居中、导航栏、等高卡片、固定 + 自适应两栏、页脚吸底；
  • 一维用 Flex、二维用 Grid，两者嵌套使用最常见。
练功 · 第二十一式
  1. 用 flex 做一条导航栏：左边品牌、右边三个链接，竖直居中； 再把窗口拉窄，看看它是怎么“挤”的。
  2. 做一行三张卡片：自动换行、间距 1rem、每张最小 200px， 并让每张卡片底部的“了解更多”永远贴在卡片底部。
  3. 思考：为什么弹性项目默认不肯缩到比内容还窄？这条默认值在什么场景下是好事， 什么场景下反而是麻烦？
参考答案 1

margin-left: auto 把右侧那一组“推”到最右边， 比 justify-content: space-between 更灵活——中间还能再插东西。 窗口变窄时，因为默认 flex-wrap: nowrap，它会先挤压、再溢出； 想让它换行就加 flex-wrap: wrap。

参考答案 2

两处 flex 各司其职：外层让卡片自动换行并平分宽度， 内层（每张卡片自己也是容器）用 flex-direction: column + margin-top: auto 把“了解更多”压到底部。

参考答案 3

因为“内容不该被切掉”是更安全的默认：比如按钮、标签、图标这类元素， 一旦缩得比内容还窄，文字会被裁掉或变形，用户看不懂也点不准。 所以规范让弹性项目默认按内容设一个最小宽度 （min-width: auto）。 好处：写卡片、按钮组时不必担心文字被压扁； 麻烦：遇到长网址、长单词、代码这类“不可断”的内容， 它宁可撑破容器也不肯缩，于是就得手动写 min-width: 0 来解除这个保护，再配合 overflow 与省略号收尾。
