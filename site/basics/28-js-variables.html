编程的第一步是“给东西起名字”。在 JavaScript 里，这件事叫变量； 而每样东西都有自己的类型——字符串、数字、真假、空…… 这一式把这两块地基打牢，后面所有的招式都站在它上面。

本式要点
  • 会声明变量，知道 let、const、var 该怎么选
  • 认得七种原始类型与对象，会用 typeof 辨认可它们的类型
  • 分得清“原始值”与“引用值”：赋值与比较时的差别是新手一大坑
  • 记得住八个“假值”，会做类型转换，会用模板字符串拼字符串

变量：名字与值

变量是一张“标签”：你给某个值贴上一个名字，以后就用这个名字找它。 声明只需一个关键字：

命名有硬规矩，也有软约定：

规则
必须 只能用字母、数字、下划线 _、美元符号 $； 不能以数字开头；不能与保留字（let、class、return…）同名； 区分大小写（name 与 Name 是两个变量）
建议 用驼峰命名：userName、totalPrice； 常量可以用全大写：MAX_RETRY； 名字要能读出意思——list 不如 todoList

中文变量名在 JavaScript 里居然是合法的（let 名字 = "墨白" 能跑）， 但请忍住不要用：输入法切换、协作、搜索都会变成麻烦。

let、const、var 该怎么选

三个关键字长得像，行为差得远。先把表格看清楚：

let const var
作用域 块级（{ } 之内） 块级 函数级（块管不住它）
能否重新赋值 能 不能（但对象内部的属性可以改） 能
能否重复声明同名 不能（报错） 不能 能（后一个覆盖前一个，静默发生）
声明前访问 报错（暂时性死区） 得到 undefined（变量提升）
建议 需要改值时用 默认就用它 别用；只在读老代码时认识它

为什么“默认用 const”？因为它把“我不打算改”明确写进了代码： 后来的人（包括三个月后的你）看到 const 就不必担心它被改过； 真需要改的时候再降级成 let，改动的意图一目了然。

    原始值与对象：一个关键差别

    原始值是按值比较与复制的；对象是按引用的—— 变量里装的不是内容，而是“内容放在哪”的地址。这一条差别，决定了新手最常遇到的误解：

    例 3 · 赋值与比较：原始值 vs 对象

      这一段是很多“灵异现象”的根源：把对象传进函数、来回赋值、 以为改的是副本，结果原对象也被改了。记住那张比喻： 原始值像便签上抄下来的字，对象像写着地址的纸条——抄地址不等于复制房子。

      顺带说一句“不可变”：原始值本身永远不能改。 var s = "abc"; s[0] = "x"; 之后 s 仍是 "abc" （严格模式下这一句还会直接报错）。所谓“改字符串”，其实都是造了一个新字符串再让变量指过去。

      真假值：判断的底层规则

      if (…)、while (…) 里的东西都会被转成真假。 转换规则很简单——假值只有八个，其余一切都是真：

      八个假值（falsy） 说明
      false 假本身
      0、-0、0n 数字零（含 BigInt 零）
      ""（空字符串） 注意：" "（含空格）是真、"0" 也是真
      null、undefined “空”的两种写法
      NaN “不是数字”也是假

      反过来，容易被误认为假的“真值”有：空数组 []、空对象 {}、 字符串 "0"、字符串 "false"。 对象永远是真，哪怕它里面什么都没有。

      三条转换纪律，能省下无数 bug：

      • 别靠隐式转换："1" + 1 得到 "11"（字符串拼接）， "1" - 1 却得到 0（减法只能算数）——这种“看运气”的行为要主动避开；
      • 比较一律用 ===：宽松相等 == 会先转类型再比， 0 == ""、"1" == 1 都为真，是 bug 温床。 （唯一常用的例外：x == null 可以一次判掉 null 与 undefined。）
      • 转数字用 Number()，解析字符串用 parseInt(s, 10)： 前者要求整串都是数字，后者会“能解析多少算多少”（第三十四式细讲）。

      模板字符串：拼字符串的正经做法

      用反引号 ` 包起来的字符串叫模板字符串，它有两个本事： 可以插值（${表达式}）、可以换行。

      例 5 · 模板字符串现场：拼一句话与一张小卡片

      ${…} 里可以放任何表达式：变量、计算、三元判断、函数调用都行， 这正是它比 + 拼接好用的原因。 本演示的第二块用了 innerHTML 与 <br>—— 那是往页面里插标签的做法；如果内容来自用户输入，绝不能这么干 （会带来 XSS 风险），要用 textContent。第三十七式会把这层安全讲清楚。

      本式小结

      • 变量是给值起的名字；命名只能用字母/数字/_/$，不能数字开头，区分大小写；
      • 默认 const，需要改值再用 let，var 只用于读懂老代码；
      • 七种原始类型：string / number / boolean / undefined / null / bigint / symbol；其余都是对象；
      • typeof null 返回 "object" 是历史遗留；判断数组用 Array.isArray()；
      • 原始值按值复制与比较，对象按引用——赋值过去的是“地址”；
      • 假值只有八个：false / 0 / -0 / 0n / "" / null / undefined / NaN，对象一律为真；
      • 比较一律用 ===，转换用 Number() / String() / Boolean()，别依赖隐式转换；
      • 拼字符串用模板字符串：反引号 + ${…}，能插值也能换行。
