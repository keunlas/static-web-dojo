一个变量装一个值，那要装一百个怎么办？答案是数组： 一列排好队的数据。它是前端用得最多的结构—— 列表、表格、待办、搜索结果，背后都是一个数组。

本式要点
  • 会创建、访问、修改数组，知道下标从 0 开始、越界得到 undefined
  • 分得清哪些方法会改变原数组、哪些返回新数组——这是最容易出 bug 的地方
  • 会用 map、filter、reduce、find、some、every 处理数据
  • 会用 sort（记得传比较函数）、at、flat、解构与展开

增删改查：先记住哪些会“动到原数组”

这是数组最容易踩的坑：有些方法直接改原数组，有些返回一个新数组。 先看“会改”的这一批（俗称“变异方法”）：

方法 做什么 返回什么
push(x)末尾加一项新长度
pop()删掉末尾一项被删掉的那一项
unshift(x)开头加一项新长度
shift()删掉开头一项被删掉的那一项
splice(起点, 删几个, …要插入的)在任意位置删、插、替换被删掉的元素组成的数组
sort() / reverse()排序 / 反转改完的原数组本身
fill(v, 起, 止)用同一个值填满区间改完的原数组本身

再看“不动原数组、返回新数组”的常用方法： slice、concat、join、map、 filter、flat、at、toSorted、 toReversed、toSpliced。 它们的价值在于“原数据保持不变”——调试时少一半困惑。

    查找：从“有没有”到“找出来”

    方法 问什么 返回
    includes(v)有没有这个值true / false（NaN 也找得到）
    indexOf(v)它在第几位下标，找不到返回 -1（对 NaN 无效）
    find(fn)第一个满足条件的元素找到就是它，找不到是 undefined
    findIndex(fn)第一个满足条件的位置下标，找不到返回 -1
    findLast(fn)从后往前找第一个满足的与 find 对称
    some(fn)有没有任意一个满足true / false（找到就停）
    every(fn)是不是全部都满足true / false（有一个不满足就停）
    filter(fn)把所有满足的收集起来新数组（可能为空）

    两个容易踩的点：every 对空数组返回 true （“全部都满足”在“一个都没有”时逻辑上成立）； indexOf 用严格相等比较，所以 [NaN].indexOf(NaN) 是 -1， 想找 NaN 得用 includes 或 findIndex 配 Number.isNaN。

        类数组与稀疏数组，两句带过
        • 类数组：arguments、NodeList（querySelectorAll 的结果） 长得像数组、能用下标和 length，但没有 map/filter。 想用数组方法就先转：Array.from(nodeList) 或 [...nodeList]（第三十七式常用）；
        • 稀疏数组：用 new Array(3) 或 delete arr[1] 会留下“空洞”， map、forEach 会跳过它们，行为别扭。日常别制造空洞—— 要占位就填 null 或空字符串。

        本式小结

        • 数组按下标访问，从 0 开始；越界得 undefined；at(-1) 取最后一项；
        • push/pop/unshift/shift/splice/sort/reverse 会改原数组； slice/map/filter/join/concat/toSorted 等返回新数组；
        • 能用不改原数组的方法就用；需要改就先复制 [...arr]；
        • 查找工具按需求选：includes / indexOf / find / findIndex / some / every / filter；
        • 迭代六兄弟：forEach 看、map 换、filter 挑、 reduce 合、some 问有没有、every 问是不是都（空数组为 true）；
        • sort 默认按字符串比，数字一定传 (a, b) => a - b；
        • 解构用来拆数组（还能交换变量、设默认值），展开用来复制与合并； 直接赋值只是起了第二个名字（引用）。
        练功 · 第三十二式
        1. 给定 const prices = [12, 5, 30, 8, 21]： 用 filter 取出大于 10 的价格，用 map 给它们打八折， 再用 reduce 求总价（保留两位小数）。
        2. 写一个函数 topN(list, n)：返回分数最高的前 n 个， 要求不修改传入的数组（提示：想清楚该用 sort 还是 toSorted）。
        3. 思考：const list = [1, 2, 3]; list.push(4); 是合法的， 但 const list = [1, 2, 3]; list = [4]; 会报错。这和 const 的作用有什么关系？
        参考答案 1

        三点值得注意：每一步都返回新数组，原来的 prices 分毫未动； reduce 一定要带初始值 0，否则空数组会直接报错； 金额最后统一用 toFixed(2) 收尾（浮点数的精度问题第三十四式细讲）。

        参考答案 2

        关键就是那句“不修改传入的数组”：函数拿到的数组属于调用者， 在里面 sort 会悄悄改掉别人的数据。 toSorted 或 slice().sort() 都能避免这件事—— 这也是第二十九式“写得让人放心”的思路在数组上的体现。

        参考答案 3

        const 锁住的是“变量与值之间的绑定”，不是值本身。 list.push(4) 改的是数组里面的内容， 变量仍然指向同一个数组，所以合法； list = [4] 则是让变量改指向另一个数组，属于“重新赋值”， 因此被 const 拒绝（报 TypeError: Assignment to constant variable）。 想让数组内容也改不了，得用 Object.freeze(list)—— 但要注意它只是浅冻结：数组里如果装着对象，那些对象的属性照样能改 （第三十三式会讲这个细节）。
