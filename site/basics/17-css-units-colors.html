写样式时最常做的两个动作是“量尺寸”与“挑颜色”。 尺子有十几种，颜色写法有七八种——这一式把它们排成一张速查表， 以后不确定用哪个单位、颜色怎么写，回来查一眼就好。

本式要点
  • 认识常用长度单位：px、em、rem、%、vw、ch， 并知道它们各自“相对谁”
  • 会用 calc()、min()、max()、clamp() 写会自适应的尺寸
  • 掌握颜色的几种写法（关键字、hex、rgb()、hsl()、oklch()）与 currentColor
  • 分清 opacity 与带透明度的颜色，知道数值里哪些能带单位、哪些不能

长度单位：相对谁很重要

每个长度单位都有“参照物”。选单位，其实是在选“跟谁一起伸缩”：

单位 相对谁 典型用途 注意
px CSS 像素（与设备物理像素无关） 边框、细线、图标尺寸 不随用户字号设置缩放，所以正文别全用 px
rem 根元素（html）的 font-size 字号、间距、整体缩放 用户改浏览器默认字号时，整站跟着变——无障碍友好
em 当前元素的 font-size 按钮内边距、与字号成比例的间距 会逐层累积：嵌套里 1.2em 会越乘越大；写在 font-size 上时相对父元素
% 包含块（父容器）的对应尺寸 宽度、栅格、比例 宽高相对父容器；padding / margin 的百分比只看宽度（第十六式）
vw / vh 视口宽 / 高的 1% 整屏区块、流体字号 手机上会出现/隐藏地址栏，vh 会跳；可用 dvh 等新单位
ch 字体里“0”这个字符的宽度 限制正文行长（行读起来舒服） 中文正文常用 30–40 个汉字宽；ch 更贴近西文
vmin / vmax 视口宽高中较小 / 较大的那个 方形元素、整屏封面 做“永远不超出屏幕”的方框时很省事
lh / ex 当前行高 / 小写字母 x 的高度 与行高、字形对齐的微调 用得少，知道有它们就行
例 1 · em 会一层层乘，rem 永远看根字号

基准段落：font-size 20px（本演示的容器设的）。

用 1.5em：变成 30px。 里面再用 1.5em：变成 45px，越套越大。

用 1.5rem：不管套多深，都是 24px。

选择建议：字号、行高、间距用 rem（或 em 让它跟字号成比例）， 边框与细线用 px，布局宽度用 % 或 flex/grid，字体度量用 ch。 这样用户调大浏览器字号时，页面整体跟着放大，而不是“文字大了、间距没动”。

例 2 · 一条“读得舒服”的正文宽度（max-width: 24ch）

不限制宽度：这一行会一直排到容器最右边，眼睛扫回来的时候容易串行，长段落尤其明显。

限制成 24ch：每行大约 24 个字符宽，读起来轻松很多。注意它是“最大宽度”，屏幕变窄时照样会跟着收缩。

数值与函数：会自己算的尺寸

除了长度，CSS 里还会用到这些数值类型：

类型 例子 说明
无单位数字line-height: 1.6、opacity: .5、flex-grow: 2行高写数字最灵活：等于“字号 × 数字”，子元素会按自己的字号重算
整数z-index: 10、column-count: 3不能写小数点
角度90deg、0.25turn旋转与渐变方向用（第二十四式）
时间.3s、300ms过渡与动画用
百分比width: 50%相对谁取决于属性（见上一节）

四个“会算数”的函数，从简单到好用依次是：

函数 作用 例子
calc() 四则运算，可混用不同单位 width: calc(100% - 2rem)（做“满宽减去内边距”）
min() / max() 取更小 / 更大的那个值 width: min(90%, 60rem)：窄屏用 90%，宽屏最多 60rem
clamp(最小, 首选, 最大) 限定在一个区间里，最常用于流体字号 font-size: clamp(1rem, 2.5vw, 1.5rem)
var() 取 CSS 变量的值 color: var(--cinnabar)（第二十五式专讲）
例 3 · calc、clamp 与 min 各显其能（把窗口拉窄再拉宽试试）

calc(100% - 4rem)：两边自然留出空隙。

clamp(1rem, 4vw, 2rem)：这行字会随屏幕宽度伸缩，但有上下限。

min(100%, 18rem)：小屏铺满，宽屏最多 18rem。

小提醒：calc() 里的 + 与 - 两侧必须有空格 （calc(100%-4rem) 会被当成无效值）；乘除的 *、/ 可以挨着写， 但除法右边必须是数字，不能是带单位的量。

颜色的写法

同一个红色，至少有五种写法。它们完全等价，挑顺手的用：

写法 例子 特点
颜色关键字red、tomato、rebeccapurple好记，但可选颜色少、不够精确
十六进制#b03a2e、#fff、#b03a2e80设计稿里最常见；末尾两位是透明度（00 全透明、ff 不透明）
rgb()rgb(176 58 46)、rgb(176 58 46 / 50%)现代写法用空格分隔，斜杠后写透明度
hsl()hsl(6 56% 44%)按“色相 / 饱和度 / 明度”调色，做深浅同色系最方便
oklch() 等新写法oklch(0.5 0.14 30)感知更均匀的新色彩空间，现代浏览器已支持；旧写法不必换
transparentbackground: transparent完全透明的颜色（不是“没有颜色”，它依然会被计算）
currentColorborder: 1px solid currentColor取当前文字颜色：图标、边框跟着文字变色时极好用
例 4 · 五种颜色写法（第 2、3、4 个色块是同一种红的三种写法）；以及 currentColor 的妙用
tomato#b03a2ergb()hsl()oklch()

我的边框用了 currentColor：把鼠标移上来，文字和边框会一起变红。

对照着看：第 2 个色块 #b03a2e、第 3 个 rgb(176 58 46)、 第 4 个 hsl(6 56% 44%) 其实是同一种红（hsl() 换算取整后略有差异，肉眼几乎分辨不出）； 第 1 个 tomato 与第 5 个 oklch() 演示另外两种表达方式。 同一个颜色，用哪种写法都行——团队里统一风格就好。

currentColor 特别值得记住：只要写一次 color， 边框、图标（用 fill="currentColor" 的 SVG）、下划线就能跟着一起变。 按钮悬停时“文字、边框、图标一起换色”，用的就是这个套路。

透明度：opacity 与带透明度的颜色

两者都能“变淡”，但作用范围完全不同：

写法 影响范围 常见用途
opacity: .5 整个元素（含所有子元素）一起变淡 整体禁用态、淡入淡出动画
background: rgb(0 0 0 / 40%) 只影响这一处的颜色 半透明遮罩、叠加色块、阴影
例 5 · 同样“半透明”，孩子遭的罪不一样
用了 opacity: .5 —— 我这块文字和背景一起变淡了。
用了 rgb(176 58 46 / 50%) —— 只有底色半透明，文字依然清楚。

还有一个无障碍细节：半透明会让文字与背景的对比度下降。 做遮罩、做淡出效果时，别忘了检查最终呈现的对比度是否还够读（第十一式的 4.5:1）。

本式小结

  • 选单位就是选参照物：字号与间距用 rem，边框用 px， 布局用 % / flex，行长用 ch，整屏用 vw/vh（注意移动端地址栏）；
  • em 相对当前元素字号（在 font-size 上则相对父元素），会逐层累积；rem 永远看根字号；
  • calc() 的加减号两侧要有空格；min()/max()/clamp() 用来写自适应尺寸；
  • 颜色五种写法等价；currentColor 让边框与图标跟着文字色走；
  • opacity 连子元素一起变淡，颜色的 alpha 只影响那一处；
  • 带单位的量不能乱乘除，数值类型要对上号（无单位数字、角度、时间）。
练功 · 第十七式
  1. 把第十二式主页的字号与间距改成 rem： 标题、正文、卡片内边距各调一次，然后在浏览器设置里把默认字号调大， 看页面是否整体跟着缩放。
  2. 做一个“流体标题”：用 clamp() 写一条规则， 让小屏时字号约 1.2rem、宽屏时约 2rem，中间平滑过渡。
  3. 思考：为什么正文用 ch 限制宽度，比写死 max-width: 700px 更耐用？
参考答案 1

验证方法：在浏览器设置里把“默认字号”从 16px 调到 20px， 用 rem 的尺寸会一起变大，用 px 的纹丝不动。 这也是为什么“全站字号都用 px”会被无障碍审计挑出来。

参考答案 2

三个参数的意思：不小于 1.2rem、不大于 2rem，中间用“1rem + 2vw”跟着视口走。 中间值写成 1rem + 2vw 这种“固定值 + 视口值”的形式， 比纯 vw 稳——小屏不会缩得太狠，大屏也不会涨得失控。

参考答案 3

因为 “一行多少字” 才是阅读舒适度的关键，而 ch 恰好是“字符宽度”这把尺子： 字号变大时，24ch 会跟着变宽，每行依然是 24 个字左右； 而写死 700px 的话，字号一变，每行的字数就跟着变—— 小字号时一行能塞下 60 个字，眼睛忙不过来。 用相对度量表达“意图”（希望一行读得舒服），比用绝对数字表达“结果”更耐用。
