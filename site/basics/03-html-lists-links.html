跳到正文

文字连成句子，句子连成段落，段落之间靠什么连接？在网页里，答案是两样东西： 列表把并列的内容排整齐，链接把一个个页面串成江湖。 传说中超文本的“超”，说的就是后面的链接。

本式要点
  • 会用 ul、ol 写无序与有序列表，并能正确嵌套
  • 会用 dl、dt、dd 写术语解释
  • 会用 a 链接到页面、锚点、邮箱与电话，并写对 target 与 rel
  • 看得懂相对路径与绝对路径，知道 ../ 与 ./ 各指哪里

无序列表与有序列表

列表用两个元素套着写：外层是列表容器，内层每一项都用 li（list item）：

  • ul（unordered list）：不分先后，浏览器默认画圆点；
  • ol（ordered list）：有先后顺序，浏览器默认自动编号。

一条硬规矩：ul 和 ol 的直接子元素只能是 li， 不能把 p、div 直接塞进去。想放别的元素，就套在 li 里面。

列表天生带缩进与项目符号，所以“看起来像列表”的内容就该用列表，而不是用一串 <br> 硬敲出来——读屏软件会念出“共三项，第一项……”， 而后者只会念成一团。

嵌套列表与编号控制

列表可以嵌套：把子列表写在某一项的 li 里面（紧跟在文字之后）。 有序列表还能微调编号——从头开始数、倒着数、换个编号风格：

属性 写在哪 作用 示例
start ol 编号从第几项开始 <ol start="3">
reversed ol 倒序编号（从大到小），布尔属性，写了就生效 <ol reversed>
type ol 编号风格：1 数字、a/A 字母、i/I 罗马数字 <ol type="A">
value li 单独指定这一项的编号 <li value="10">

嵌套时按层级缩进写，自己能一眼看出谁属于谁；浏览器会用不同的符号区分层级 （圆点、圆圈、方块轮流出现），所以一眼就能看出“这是第二层”。

描述列表：术语与解释

还有一类内容天生是“名词 + 解释”的关系，比如词典条目、参数表、常见问题。 它们用描述列表（description list，旧称定义列表）来写：

  • dl：整个列表；
  • dt：被解释的词（term）；
  • dd：对这个词的解释（description），一个词可以配多条解释。

链接：页面之间的小径

a 元素（anchor，锚）负责跳转，最重要的属性是 href （hypertext reference），它指出“跳到哪去”。常见去处有四种：

去处 写法 说明
另一个页面 href="02-html-text.html" 站内的相对路径，最常用
本页的某处 href="#section-id" 锚点跳转：目标元素要有对应的 id，页内目录就是这么做出来的
写邮件 href="mailto:you@example.com" 点击后打开本机邮件客户端
打电话 href="tel:+8613800000000" 手机上点击直接拨号，国际写法以 + 开头

两个与“打开方式”有关的属性：

  • target：target="_blank" 表示在新标签页打开。 现代浏览器已默认按 rel="noopener" 处理它，显式写上更稳妥，也照顾老浏览器；
  • download：让浏览器直接下载而不是打开，可附带建议的文件名： <a href="report.pdf" download="年度报告.pdf">。
心法：链接文字要能“独立成句”

避免“点这里”“更多”这种写法。读屏软件会把页面上的链接单独列出来供人跳转， 一屏的“点这里”等于什么都没说。把链接文字写成它要去的地方： “上一式：文本与语义”永远比“点这里”清楚。

路径：告诉浏览器文件在哪

写链接时最常出错的地方就是路径。记住三条规则，之后就不容易错了： 同目录直接写文件名，./ 就是“当前目录”，../ 表示“上一层”。

写法 含义 举例
02-html-text.html 当前目录下的文件 本式链接第二式
./02-html-text.html 同上，./ 显式表示当前目录 意思一样，写出来更“看得见”
../index.html 上一层目录下的文件 从 basics/ 回到站点首页
images/cat.jpg 子目录里的文件 把图片放进 images 文件夹
/index.html 以站点根目录为起点的绝对路径 部署在服务器上没问题；file:// 双击打开时不可用
https://example.com/a.html 完整地址（绝对 URL），可以指向任何网站 外链；离线站点应尽量少用

本站所有页面都用相对路径，就是为了双击打开也能正常跳转—— 这也是“完全离线可用”的关键。另外记得：指向一个目录时，服务器会自动送出该目录下的 index.html，所以 basics/ 与 basics/index.html 是同一个页面。

排查链接失效的三步
  1. 先看文件名有没有拼错、大小写是否一致（服务器区分大小写）；
  2. 再看层级：从当前文件所在文件夹出发，往上几层、往下几层，画一遍目录树就清楚了；
  3. 最后看后缀：.html 有没有漏写，路径里有没有混进中文标点或空格。

本式小结

  • 并列内容用 ul，有先后用 ol，每一项都装进 li；
  • 嵌套列表写在 li 里面；start、reversed、type、value 可以微调编号；
  • “词 + 解释”用 dl / dt / dd；
  • 链接用 a 加 href：页面、锚点、邮件、电话四种去处；
  • 新窗口用 target="_blank"，配上 rel="noopener"；下载用 download；
  • 路径三件套：./ 当前目录、../ 上一层、直接写文件名同目录；以 / 开头的是站点根，file:// 下不可用。
