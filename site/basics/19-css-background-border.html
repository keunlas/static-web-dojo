骨架、间距、文字都齐了，该给盒子“上漆”了。 这一式把背景、渐变、边框、圆角与阴影一次讲完—— 它们是最容易做出“精致感”的一组属性，也最容易做过头。

本式要点
  • 掌握背景全家桶：颜色、图片、位置、尺寸、重复、裁切与多重背景
  • 会用三种渐变（线性、径向、锥形）当背景，知道“渐变是图不是颜色”
  • 会写边框三要素与单边边框，理解 border-style 缺了就不显示
  • 会用 border-radius 做圆角、正圆与胶囊，用 box-shadow 做层次

背景全家桶

背景可以拆成六件事分别控制，也可以写在一行简写里：

属性 管什么 常用取值
background-color 底色 任何颜色；transparent 是默认值
background-image 背景图（也可以放渐变） url("…")、linear-gradient(…)，多个用逗号分隔
background-repeat 要不要平铺 repeat（默认）、no-repeat、repeat-x / repeat-y
background-position 放在哪 center、left top、50% 100%、1rem 2rem
background-size 画多大 auto（原始尺寸）、cover、contain、100% 100%
background-clip 画的边界 border-box（默认）、padding-box、content-box、text
background-attachment 跟不跟着页面滚 scroll（默认）、fixed（移动端表现不稳，慎用）
例 1 · cover、contain 与拉伸的区别（同一张图，三个盒子）
cover：铺满，可能裁边
contain：完整，会留白
100% 100%：拉伸变形

三个取舍记住就行：cover 保证铺满（会裁）、 contain 保证看全（会留白）、百分比拉伸会变形。 做整屏大图用 cover 配 background-position: center； 做图标、图案用 contain 或不设 size。

背景图的另一个小本事是多重背景：用逗号分隔，写在前面的画在上层。 一条常见套路是“上一层渐变、下一层图片”：

渐变：当背景用的图

渐变在 CSS 里属于“图”（<image>），不是颜色——所以它写在 background-image 上，而且可以和高低层叠、和底色叠加。三种最常用：

函数 形状 例子
linear-gradient() 线性（一条直线上的过渡） linear-gradient(135deg, #f4edde, #e9f0e4)；也常用来做硬边条纹
radial-gradient() 径向（从中心向外扩散） radial-gradient(circle at 30% 30%, #f3e3dd, transparent 70%)：做光晕
conic-gradient() 锥形（绕中心扫一圈） conic-gradient(#b03a2e 0 25%, #f4edde 0 50%, #b03a2e 0)：做色轮、进度环
例 2 · 三种渐变，以及渐变叠图案的用法
linear 线性
radial 径向
conic 锥形
repeating 条纹

两个实用细节：其一，径向渐变里的 transparent 在部分浏览器会带出灰边， 更稳的写法是让它过渡到与底色相同的颜色（如 rgb(255 253 247 / 0)）； 其二，色标可以写两个位置做硬边： linear-gradient(90deg, #b03a2e 0 40%, #f4edde 40% 100%) 会在 40% 处直接断开，而不是渐变过去。

边框与圆角

边框有三要素：宽度、样式、颜色。三个都必须“有值”才能显示—— 最常见的坑就是只写了宽度忘了样式（默认是 none，等于不画）：

写法 说明
border: 1px solid #d4cab0最常用：细实线
border-top: 2px dashed #b03a2e只给某一边加边框（上/右/下/左都行）
border-width: 2px（没写 style）不会显示——这是新手第一个坑
border-stylesolid、dashed、dotted、double、none 等
border-image用图片当边框（做花边），用法较复杂，日常少用
outline轮廓：不占布局空间，常用于焦点提示（:focus-visible），现代浏览器里也会跟随圆角

border-radius 负责圆角，写法与 padding 一样按顺时针； 斜杠前后可以分别写水平与垂直半径，做椭圆角：

阴影：让层次浮起来

box-shadow 的五个参数依次是： 横向偏移、纵向偏移、模糊半径、扩散半径、颜色， 前面加 inset 关键字就变成内阴影；多个阴影用逗号分隔（先写的在上层）。

写法 效果
box-shadow: 0 2px 6px rgb(0 0 0 / 12%)最常见：卡片轻轻浮起来
box-shadow: inset 0 1px 3px rgb(0 0 0 / 18%)内阴影：凹槽感（输入框、按压态）
box-shadow: 0 1px 2px rgb(0 0 0 / 10%), 0 8px 20px rgb(0 0 0 / 12%)两三层叠加：更自然（近处实、远处虚）
box-shadow: 0 6px 18px rgb(176 58 46 / 25%)带颜色的阴影：呼应主色，适合强调按钮
box-shadow: none去掉阴影（很多类库会统一给卡片加阴影）

一层轻阴影
两层更自然
带主色的阴影

心法：阴影要克制，也要有方向
  • 别给页面上每个盒子都加阴影：全场都是浮起来的卡片，反而谁都不突出；
  • 方向要一致：全站阴影都朝下（如 0 Npx Npx）， 看起来才像同一个光源照下来的；
  • 别用纯黑：rgb(0 0 0 / 12%) 这类低透明度更自然， 也可以带一点主色；
  • 动画阴影要小心：阴影重绘成本不低，做悬停放大时， 动画 transform 比动画 box-shadow 流畅得多（第二十四式）。

背景裁切要用 color: transparent 把字“掏空”，图案才透出来； 记得同时写 -webkit-background-clip: text，兼容性更稳。

可访问性提醒

渐变文字与低对比度的“淡色小字”是两处高发的对比度陷阱： 文字被裁成图案后，对比度取决于图案本身。 用之前想一想：如果图案正好是浅色，这行字还看得清吗？ 拿不准就用纯色文字，把渐变留给装饰（第十一式的 4.5:1 是底线）。

本式小结

  • 背景六件事：颜色、图、重复、位置、尺寸、裁切；多重背景用逗号，先写的在上层；
  • cover 铺满会裁边、contain 看全会留白、百分比拉伸会变形；
  • 渐变是“图”不是颜色，写进 background-image，可以与底色、图片叠着用；
  • 边框三要素缺一不可，只写 width 不写 style 等于没边框； outline 不占空间，适合做焦点提示；
  • 圆角三档：10px 卡片、999px 胶囊、50% 正圆；斜杠可写椭圆角；
  • box-shadow 顺序是“横 纵 模糊 扩散 颜色”，inset 做内阴影，多层叠加更自然；
  • 阴影克制、方向一致、别用纯黑；background-clip: text 能做出渐变文字，但要注意对比度。
练功 · 第十九式
  1. 做一张“封面卡片”：用 cover 铺一张背景图，叠一层深色渐变， 再放一个标题；把卡片四角做成 12px 圆角。
  2. 给第十二式主页的按钮加悬停反馈：默认一层轻阴影， 悬停时阴影加深并上移 1px（提示：用 translateY 或 margin 都可以，想想哪个更合适）。
  3. 思考：为什么“只写 border-width”看不到边框，而“只写 box-shadow” 却能看到阴影？这两个属性的设计思路有什么不同？
参考答案 1

要点：渐变写在前面（上层）、图片写在后面（下层）； 渐变里用半透明黑，才能既压暗图片又保留细节；文字用浅色保证对比度。

参考答案 2

用 transform 更合适：它不会让元素在布局里“真的挪位”， 周围元素不会跟着抖动，而且动画通常由合成线程处理，比改 margin 流畅。 （过渡与变形是第二十四式的主题。）

参考答案 3

因为两者的“默认值”完全不同：border-style 的初始值是 none， 没有样式就谈不上画线，宽度自然无效——这是“先有形态，再谈尺寸”的思路； 而 box-shadow 的默认值是 none（不画）， 可一旦你给出偏移与颜色，它就有了完整信息，于是直接画出来。 换句话说：边框必须先选“用什么线”，阴影只需要“往哪画”。
