本式要点

网页是怎么来的

HTML（HyperText Markup Language，超文本标记语言）不是编程语言， 它是一门标记语言：用一套约定的标签，把“这是标题”“这是段落”“这里插一张图” 说给浏览器听。浏览器读完这些标记，再把它们画成你看到的页面。

一个网页通常由三样东西组成，记住这个分工，整个基础篇都不会迷路：

  • HTML 是骨架——内容与结构：标题、段落、图片、链接、表单；
  • CSS 是外衣——颜色、字号、间距、布局（第十三式起讲）；
  • JavaScript 是灵魂——点击、输入、计算等一切“会动”的部分（第二十七式起讲）。

还有一件让人安心的事：HTML 文件就是纯文本文件。 用记事本、VS Code 或本站的练功场写都行， 写错了也不会爆炸——最坏的结果只是页面上少显示一样东西。

写法 它在说什么
<!doctype html> 声明“这是一份 HTML 文档，按最新标准解析”。它必须写在第一行。
<html lang="zh-CN"> 整个文档的根元素。lang 说明页面主要用简体中文，屏幕阅读器与搜索引擎都靠它判断读音与语种。
<head> 写“给浏览器看”的信息：编码、标题、样式表、脚本。它里面的内容不会直接显示在页面上。
<meta charset="utf-8"> 声明文本编码。少了它，中文可能变成乱码——新手第一个月最常见的坑。
<title> 标签页标题与收藏夹里的名字。每个页面都要有，且写清是什么页面。
<body> 写“给人看”的内容：页面上一切可见的东西都住在它里面。
心法：head 与 body 的分工

记一句话就够：head 是档案，body 是门面。 以后遇到“为什么这行字没显示”的问题，先看看它是不是写错进了 head。

元素、标签、属性

接下来的三个词，是本篇里出现频率最高的行话，一次说清：

  • 标签（tag）：尖括号包起来的那一段，如 <h1> 与 </h1>，后者多一条斜杠表示“结束”；
  • 元素（element）：开始标签 + 内容 + 结束标签的整体，如 <h1>你好</h1>；
  • 属性（attribute）：写在开始标签里、给元素补充说明的键值对，如 href="…"、title="…"。

还需要知道哪些元素有“结束标签”：绝大多数元素成对出现，但少数元素没有内容， 所以不需要结束标签，例如 <meta>、<img>、<br>、<input>。

注释：写给未来的自己

<!-- 和 --> 之间的一切都是注释：浏览器解析时会直接忽略， 页面上看不见，但查看源代码时能看到。它是留给同伴（以及三个月后的自己）的备忘。

例 3 · 注释不会显示在页面上

我的上下各藏了一行注释，但页面上只看得到这两段文字。

在页面上右键 →“查看网页源代码”，就能看到它们。

注释还有一个实用场景：调试时把暂时不要的一整段内容注释掉， 改完再放开。注意不要用注释藏密码或隐私——查看源代码的人一眼就能看到。

文件与文件夹：网页的第一课

网页是一个个文件，所以“怎么给文件起名、怎么放”从一开始就要养成习惯：

  • 首页固定叫 index.html：访问一个文件夹时，服务器会自动送出这个名字的文件——本站的每一回都是从 index.html 开始的；
  • 文件名用小写字母、数字与连字符：about-me.html 是稳妥的写法，避免空格、中文与大小写混用（有些服务器区分大小写，本地能打开、上传就 404）；
  • 后缀是 .html：写成 .htm 也能用，但别写成 .txt（那会变成“下载一段文本”而不是“打开网页”）；
  • 文件按用途分文件夹：本站就是 basics/、bootstrap/、assets/ 这样分开放的。

文件之间的互相引用叫路径：images/cat.jpg 是“当前文件夹下的 images 文件夹里”， ../assets/logo.svg 里的两个点表示“回到上一层”。 路径写错是新手第二大坑，好在第三式讲链接时会专门练它。

动手第一课：你的第一个页面

十分钟，不用装任何东西：

  1. 在桌面或任意位置新建一个文件夹，取名 my-first-page；
  2. 在文件夹里新建一个文本文件，重命名为 index.html（注意后缀必须是 .html）；
  3. 用编辑器打开它，把上面那份“页面骨架”原样抄进去、保存（UTF-8 编码）；
  4. 回到文件夹，双击 index.html——浏览器里就出现了你的第一个网页；
  5. 把标题里那句话改掉，保存，再回浏览器按 F5 刷新——页面跟着变了。

再教你两个好习惯：其一，遇到好看的网页，右键选“查看网页源代码”，看看别人怎么写—— 这是最好的免费教材；其二，嫌新建文件麻烦时，先来本站的 练功场——三栏编辑器，随手写、随手看效果，代码还会存在你自己的浏览器里。

新手常踩的三个小坑
  • 改了代码浏览器没变化——先确认已保存，再按 F5 刷新；
  • 页面出现乱码——在 <head> 里补上 <meta charset="utf-8">，并在编辑器里把文件存为 UTF-8；
  • 双击打开后满屏是代码——多半是后缀写成了 .txt，把文件名改回 .html 即可。

本式小结

  • HTML 用标签描述内容的结构；浏览器负责把标记画成人能看的网页；
  • 页面骨架八行起步：doctype → html → head → body；
  • 元素 = 标签 + 内容 + 结束标签；属性写在开始标签里；img、meta 这类元素没有结束标签；
  • 注释写给自己人看，页面上不显示；
  • 页面是文件：首页叫 index.html，文件名用小写与连字符，路径要写对。
练功 · 第一式
  1. 不看教程，手写出那份八行骨架，并让它显示一个标题、两个段落。
  2. 给你的页面加上注释：用注释写清“这一段是自我介绍”，并在页面上查看源代码确认注释在那里。
  3. 思考：既然浏览器能自动忽略注释与多余空格，为什么还要讲究缩进和分层？ （提示：写给谁看？）
参考答案 1

两段文字各写一个 <p>，不要用换行去“凑”段落—— HTML 会把连续换行合并成一个空格，第二式讲空白折叠时会细说。

参考答案 2

保存后刷新页面，再右键 →“查看网页源代码”，搜一搜“自我介绍”， 能搜到就说明注释写得没错；页面上看不到它，说明注释确实只写给看源码的人。

参考答案 3

因为浏览器不在乎缩进，但人在乎。代码是写给未来的自己的： 缩进能让嵌套关系一眼可见，分层能把“结构”“样式”“脚本”分开。 你省下的那点空格，会在某天排查问题时加倍还回来。
