跳到正文

CSS 十四式学完，该交答卷了。这一式不教新属性，只做一件事： 给第十二式那页“光着身子”的个人主页穿上衣服—— 而且不改动它的结构，一行语义都不动。

本式要点
  • 体验“结构不动、样式全换”的工程感：HTML 是骨架，CSS 是外衣
  • 用设计令牌（CSS 变量）统一颜色、间距、圆角与字体
  • 把 Flex、Grid、媒体查询、动效、无障碍照顾一次用齐
  • 用一份验收清单给成品打分，找出自己的盲区

成品先看

两页对照着看，差别一眼就明白——它们的 HTML 结构几乎一模一样：

  • 第十二式的成品：纯 HTML 版（浏览器的默认样式）；
  • 第二十六式的成品：穿上衣服版（本式新加的样式）。

改了哪些东西？大致是这些，每一项都能在前面的式子里找到出处：

这一式做了什么 用到的式子
一组设计令牌（颜色、间距、圆角、字体栈）第十三、十七、二十五式
正文排版：字体、字号、行高、行宽第十六、十八式
整页骨架：窄屏单列、宽屏“正文 + 侧栏”第二十二、二十三式
卡片、标签、分隔线、阴影与悬停动效第十九、二十四式
表单与按钮：输入框、聚焦轮廓、按钮反馈第七、十九、二十四式
照顾“减少动态效果”的读者、跳过链接第十一、二十三式

动手拆解

下面六步就是成品页 <style> 里的全部内容，按顺序读一遍即可。 建议你打开自己的主页，跟着一段段加。

第一步 · 变量先行：先把“尺子”定下来

动手写第一条规则之前，先把会重复出现的值收进变量。 这一步花五分钟，后面能省一小时的搜索替换。

注意命名用的是用途而不是颜色值：--accent 比 --red 耐用—— 哪天把强调色换成墨蓝，名字不用动。

第二步 · 排版与底色

接下来给页面定基调：盒模型统一、底色、字体、行高，以及标题、链接、图片的规矩。

四个细节值得留意：box-sizing: border-box 让宽高所见即所得（第十六式）； line-height: 1.8 是中文正文的舒适区（第十八式）； 标题用流体字号 clamp()，小屏不挤、大屏不飘（第十七、二十三式）； img { max-width: 100% } 让图片永不撑破容器（第四、十六式）。 另外注意背景色写在 html 上、限宽与内边距写在 body 上： 这样既能让底色铺满整屏，又能让内容居中留白——两件事各归各的元素。

第三步 · 用 Grid 搭骨架

这一页最“得意”的一段：直接让 body 当网格容器， 用模板区域描述整页骨架。这样做的好处是——一个包装用的 div 都不用加， HTML 才能和第十二式那版一模一样。

这里有两处“防坑”写法：minmax(0, 1fr) 防止长内容把正文列撑宽 （第二十二式讲过 1fr 最小值是 auto 的坑）； 侧栏加了 align-self: start，不被拉伸到与正文一样高。 整页的响应式只用了一句媒体查询——骨架够简单，就不需要写一堆断点。 顺带一提：grid-template-areas 里那些引号中的单词，就是你在 grid-area 里用的名字（第二十二式例 4 见过它的画图玩法）。

第四步 · 卡片、标签与分隔线

作品与日志都用 .card：纸白底、细边线、圆角、内边距， 再给悬停与键盘聚焦一点反馈。这里只动 transform 与阴影，最省性能（第二十四式）。

:focus-within 是这一处的小心思：卡片里任何一个链接被键盘聚焦时， 整张卡片都会有反馈，键盘读者不会“迷路”。

第五步 · 表单与按钮

表单最容易做得难看又难用。font: inherit 让输入框继承页面字体； 聚焦时给一圈清晰的轮廓（第十一式的规矩：焦点必须看得见）。

按钮做到了 44px 左右的高度（padding: .5rem 1.1rem 加行高）， 触屏上点得准（第二十三式的触控目标）；输入框宽度 100%， 在窄屏上自然铺满，不需要额外断点。

第六步 · 收尾：跳过链接与“减少动态效果”

最后两件小事，都是给别人省心的：跳过链接平时藏起来、按 Tab 第一下就现身； 动画则在系统要求“减少动态效果”时安静下来。

对照验收清单

成品页交付前，逐条过一遍。每一条都能在浏览器里当场验证：

  • 结构没动：与第十二式那页相比，标签序列完全一致 （用脚本逐节点比对过），只多了 class 属性； 全页唯一改动的文字是页脚那一句（把“纯 HTML 手写”改成“手写 HTML 与 CSS”）；
  • 键盘可用：按 Tab 从跳过链接开始走一遍，所有链接、卡片、表单都能到达， 焦点都看得见；
  • 对比度够：正文与次要文字在纸底上都读得清（4.5:1 底线）；
  • 窄屏不散：拉到 320px 宽，正文单列、图片不溢出、按钮不跑到屏幕外；
  • 宽屏不垮：拉到 1600px 宽，内容不会拉成一条难以阅读的长线 （--measure: 64rem 在守着）；
  • 缩放 200%：浏览器缩放到 200%，内容不重叠、不出现横向滚动条；
  • 减少动效：在系统里打开“减少动态效果”，卡片悬停不再位移；
  • 没有行内样式：成品页里 style="…" 出现次数为 0—— 样式全部住在样式表里。
心法：样式改到满意，再回头看结构

这一式的关键是“结构一行没动”。如果为了样式好看， 回去把 article 换成 div、把 h2 降成 h4，那说明结构当初就没搭对。 好的骨架应该能穿任何衣服——这也是基础篇先讲 HTML、再讲 CSS 的原因。

本式小结

  • CSS 综合修炼的六步：设计令牌 → 排版底色 → 网格骨架 → 卡片标签 → 表单按钮 → 无障碍与偏好收尾；
  • 每一步都对应前面某一式：变量（25）、排版（18）、网格与响应式（22、23）、 阴影与动效（19、24）、表单与焦点（7、11）；
  • 骨架够简单时，整页只需要一句媒体查询；能靠流体尺寸与网格解决的，就别加断点；
  • 交付前过一遍验收清单：结构没动、键盘可用、对比度够、窄屏不散、宽屏不垮、200% 可读、动效可关、无行内样式；
  • CSS 部分到此结束——你已经能独立写出一页结构清楚、看着舒服、谁都能用的主页了。
练功 · 第二十六式
  1. 照着六步，把你自己第十二式做的个人主页打扮一遍；完成后把两版都留着，对照着看。
  2. 给成品加一套深色主题：把颜色变量收进 :root， 再写一份 [data-theme="dark"] 的值，手动切换试试。
  3. 思考：为什么最后一步才做“跳过链接”和“减少动态效果”？ 如果一开始就做，会有什么不同？
参考答案 1

没有唯一答案，用上面的验收清单逐条核对。常见的三处失手： ① 卡片里写了 height，结果文字一多就溢出（改成 min-height 或者干脆不写）； ② 忘记给图片 max-width: 100%，窄屏被撑破； ③ 悬停效果只写了 :hover，键盘读者没有反馈（补 :focus-within / :focus-visible）。

参考答案 2

检查点：把 <html data-theme="dark"> 手动改一下， 整页应当立刻换色。凡是没变的地方，就是还写着写死的颜色值—— 回去把它们换成变量即可。

参考答案 3

因为它们属于“先有内容、再谈照顾”这一类收尾工作： 跳过链接要指向正文的 id，而正文的锚点与结构是在前面几步定下来的； 减少动效的规则要针对具体的动画属性来写， 而动画是第四、五步才加的。放在最后做，可以一次看清“哪些动的东西需要关掉”。 如果一开始就写，往往写完还得回头改两遍。 这和写代码的规律一样：结构先定、细节后补、无障碍与性能在收尾时统一过一遍。
