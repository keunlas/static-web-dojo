跳到正文

一页全是字，看久了眼睛发涩。该给页面添几张图了—— 但在网页里放图，讲究的不是“好看”，而是说清楚这张图是什么。 这一式把 img 的每一样家当都过一遍。

本式要点
  • 会写完整的 img：src、alt、width 与 height
  • 知道什么时候该写 alt=""，什么时候必须认真写描述
  • 看得懂常见图片格式的取舍，知道 SVG 为什么适合图标与示意图
  • 见过响应式图片的两套写法：srcset / sizes 与 picture

img 的三样家当

img 是少数没有结束标签的元素，它的信息全靠属性：

属性 必填？ 作用
src 必填 图片文件在哪（相对路径或完整地址）
alt 必填 替代文字：图片加载失败时显示，读屏软件会念出来
width / height 强烈建议 给浏览器预留空间，避免图片加载完成后把下面的内容“顶下去”
loading="lazy" 按需 滚动到附近才加载，长页面下方的大图值得写上
decoding="async" 按需 提示浏览器异步解码，减少卡顿（老浏览器会忽略，无副作用）

alt 怎么写才算合格

alt 是全篇最容易写敷衍的属性，但它的价值极高： 读屏软件的读者、图片加载失败的读者、搜索引擎，靠的都是它。三种情况分开处理：

  • 图片是内容：写它传递的信息，比如“纸墨风格的山水示意图，一轮红日与远山”。 不要把开头的“图片”“照片”写进去——读屏软件会自己念“图片”，重复了；
  • 图片纯装饰（分隔线、背景花纹）：写空值 alt=""， 读屏软件会直接跳过，不会念一堆废话；
  • 图片本身是链接：alt 要写“点了会去哪”，如“回到首页”； 因为这时链接的文字就是这张图。

还有一条底线：不要把文字做成图片。图片里的字没法选中、没法翻译、 放大就模糊，读屏软件也读不出来。

心法：图片加载失败时的那行字

断网打开页面时，alt 就成了图片的替身。你可以把它当成一个自检标准： 如果把它当成图注来读也通顺，那这条 alt 就是合格的。

图片是行内元素

这一点和很多人的直觉相反：img 默认是行内元素， 会和文字排在同一行，并且默认按文字基线对齐—— 于是图片下方常常莫名其妙多出一点空隙。这个现象以后学 CSS 会彻底解决， 现在先认识它。

例 2 · 图片与文字同排时，底边对不齐

看这行文字和图片是并排的，注意图片底部的空隙。

解决办法：把它单独放一段（如例 1），或者用 CSS 调整对齐与显示方式。

图文配对：figure 与 figcaption

有图有说明时，别用两个段落硬拼，用 figure（图组）包起来、 用 figcaption（图注）写说明。好处是机器知道“这段文字是在说这张图”， 而且图注放在图片上方或下方都合法。

常见图片格式怎么选

浏览器能显示很多格式，选择的标准是“内容类型 + 体积 + 兼容性”：

格式 适合 注意
.jpg / .jpeg 照片、颜色丰富的图 有损压缩，反复编辑会越存越糊；不支持透明
.png 截图、需要透明或锐利边缘的图 无损，体积通常比 JPEG 大
.gif 极短的循环小动画 颜色最多 256 色，画质差；新项目更推荐视频或 CSS 动画
.webp 现代网站的通用选择（照片与图形都行） 支持透明与动画，体积通常小于 JPEG / PNG；老浏览器可能不认
.avif 追求更小体积的照片 压缩率更高，但编码慢、兼容性略逊于 WebP
.svg 图标、logo、示意图 矢量：放大不糊，体积小，还能用文本编辑器改

SVG 值得单独说一句：它其实是一段描述图形的 XML 文本，本站所有示例图都是手写的 SVG。 它既能用 img 引入，也能直接写进 HTML—— 当普通标签用时，它的每个图形元素都能被 CSS 选中、上色。

响应式图片：按屏幕挑一张

手机屏幕小、网速可能慢，给它一张 2000 像素宽的大图是浪费；高清屏又需要更清晰的图。 HTML 提供了两套写法让浏览器自己挑：

  • srcset + sizes：同一张图的多个尺寸， 告诉浏览器“每个文件多宽”“显示时大约占多宽”，由它决定下载哪个；
  • picture + source：不同条件下用不同的图， 比如窄屏换成竖版构图、或者优先用 WebP、不支持时退回 JPEG。

这两种写法都需要准备多个图片文件，所以更适合有素材管道的项目； 本站的示例图是 SVG，天生可以无限缩放，用不上 srcset。 记住它们的存在与用途，等以后真的用上再回来抄语法即可。

别忘了图片也能被点击

想让图片点开看大图，把 img 包进 a 里就行： <a href="big.jpg"><img src="small.jpg" alt="…"></a>。 这时 alt 要写“点开看大图”的意图，而不是描述图片内容。

本式小结

  • img 的三样家当：src 找图、alt 说明图、width/height 预留位置；
  • 内容图写清描述，装饰图写 alt=""，链接图写“点了去哪”；
  • 图片是行内元素，默认按基线对齐，所以会看到“底部空隙”；
  • 图文配对用 figure + figcaption；
  • 格式选择：照片用 JPEG/WebP，透明与截图用 PNG，图标示意图用 SVG，GIF 已基本过时；
  • 响应式图片两套写法：srcset/sizes 挑尺寸，picture 挑不同图。
练功 · 第四式

  2. 写一段“点击缩略图看大图”的链接（图片文件不存在也没关系，先把结构写对）。
