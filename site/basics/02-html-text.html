跳到正文

网页上最多的东西是文字，而文字最讲究“身份”：哪句是标题、哪句是重点、 哪段是引用别人的话。这一式，我们把每一个标签用到它该用的地方。

本式要点
  • 用 h1–h6 搭出标题层级，不跳级、不把标题当字号用
  • 分清 p、br、hr 的职责，理解浏览器的空白合并规则
  • 用 strong、em、mark、del、ins 表达语气
  • 会写引用、代码、缩写、上下标与字符实体

标题：六级台阶

h1 到 h6 表示六级标题（heading），数字越小级别越高。 它们不只是“大号字”，而是页面的目录骨架：读屏软件靠它给读者导航， 搜索引擎靠它判断页面重点。三条规矩请记牢：

  • 一个页面只有一个一级标题，说明“这一页是什么”；
  • 层级逐级向下：二级下面才用三级，不要从 h2 跳到 h4；
  • 想让字变小、变灰，那是 CSS 的事——不要为了样式挑标题级别。

平时写作，用 h1 报上页面主题，用 h2 分小节、h3 分小点， 四五级已经很少见了。瞧，本站每一式右侧的“本式目录”，就是由正文里的 h2、h3 自动生成的——标题写得好，目录就好用。

段落、换行与水平线

p 是段落，是正文的默认容器。br 是强制换行（line break）， 一般只用在“地址、诗歌”这类换行本身就是内容的地方； hr 是水平线（horizontal rule），表示话题的转折，而不是“画一条线好看”。

心法：连续的空格、换行、缩进都只算一个空格

这条规则叫空白折叠。它有两个直接后果：其一，想让文字断开，得用元素而不是回车； 其二，代码缩进怎么写都不会影响页面——大胆缩进，让自己看得舒服。 唯一的例外是 pre 元素，它里面的空白原样保留（本节最后会见到它）。

强调与语气

同一句话，重音不同，意思就不同。HTML 提供了几对小工具来表达语气， 它们的用法区别在于“有没有语义”：

标签 含义 怎么选
strong 重要、严重 “注意！这条必须看”——有语义，优先用它
b 粗体 只是视觉上加粗（如产品名），没有强调意味时才用
em 强调、重读 语气上的重音：“是他干的”
i 斜体 外来词、术语、心里话等约定俗成的场合
mark 高亮标记 像荧光笔划重点，比如搜索结果里的关键词
del / ins 删除 / 新增 改稿留痕：原价与现价、修订说明
small 附带说明 版权声明、法律小字这类“次要信息”

它们的默认样子（粗体、斜体、黄底、删除线）是浏览器给的； 语义是给机器（读屏软件、搜索引擎）看的。用对标签，两种读者都满意。

引用、代码与其它行内元素

写文章还会经常遇到这几类内容，各有专用标签：

  • 引用：整段引用用 blockquote（独立成块），句中短引用用 q（浏览器自动加引号），来源用 cite；
  • 代码：行内代码用 code，多行代码用 pre 包住 code（保留空白与换行）；
  • 键盘与输出：kbd 表示按键，samp 表示程序输出，var 表示变量名；
  • 缩写：abbr 配 title 属性，鼠标悬停能看到全称；
  • 上下标：sub 与 sup，写化学式与脚注1时用得上。

特殊字符：字符实体

问题来了：小于号 < 是 HTML 的“语法符号”， 直接写出来浏览器会以为要开始一个标签。写“小于号本身”要用字符实体 （character entity）：一个以 & 开头、以 ; 结尾的短代码。

例 5 · 用实体写出特殊字符

心法：&nbsp; 别拿来排版

新手常用一串 &nbsp; 把文字“顶”到想要的位置。 它确实能用，但那是用空格做设计的下策：一旦屏幕变窄，页面就会散架。 空白的活儿，以后交给 CSS 的 margin 与 padding（第十六式）。

本式小结

  • 标题是结构不是字号：一个 h1，层级逐级向下，不跳级；
  • p 是段落，br 只在换行本身有意义时用，hr 表示话题转折；
  • 空白折叠：连续空格与换行都算一个空格，pre 是唯一例外；
  • 语气标签优先选有语义的：strong、em、mark、del、ins；
  • 引用用 blockquote / q，代码用 code / pre，缩写用 abbr；
  • 特殊字符用实体：&lt;、&gt;、&amp;、&copy;……
