选择器：轻剑的眼睛

$() 里传入一个选择器字符串，它就会返回一个 jQuery 对象——本质是一个“元素集合”。 哪怕一个元素都没命中，它也不会报错，只是返回一个空集合；反过来，命中多个元素时， 大多数方法会自动对集合里的每一个元素执行，这就是上一式说的“隐式遍历”。

属性选择器

元素身上穿的“属性”也能当线索：[attr] 表示“有这属性就行”， [attr=val] 要求值完全相等，[attr^=val] 要求值以 val 开头。 jQuery 还支持 [attr$=val]（结尾）与 [attr*=val]（包含）。

旁边的数字输入框纹丝不动——[type="text"] 只认文本框。 属性选择器在表单里特别好用：input[required]、input[type="email"] 都是家常便饭。

位置选择器与方法

:first、:last、:even、:odd 按“在集合里的位置”选人。注意 jQuery 从 0 起数，所以 :even 选中的是第 1、3、5……个。

心法：方法比伪类更趁手

这几个位置伪类是 jQuery 的“私房扩展”，不属于标准 CSS。现代 jQuery 更推荐对应的过滤方法： $('li').first()、$('li').eq(2)。理由有二——性能： 浏览器原生不认识 :first 这类伪类，jQuery 得自己多扫一遍；可读性： .first() 一眼就懂，:first 还容易与 CSS 的 :first-child 混淆。 江湖规矩：伪类能用，但方法更体面。

表单选择器

表单是网页里最需要“挑挑拣拣”的地方：哪些框填了、哪些勾了、哪些被禁用…… jQuery 为表单备了一组专用伪类，写法上都以冒号开头，可以直接拼在别的选择器后面。

选择器选中谁
:input全部表单控件：input、textarea、select、button 一个不落
:text / :password / :file按 type 挑文本框 / 密码框 / 文件框
:checkbox / :radio / :submit按 type 挑复选框 / 单选按钮 / 提交按钮
:checked被勾选的复选框、单选按钮，以及被选中的下拉项
:selected下拉框里被选中的 <option>
:disabled / :enabled被禁用 / 可用的控件
心法：状态伪类要“现查现用”

勾选、选中、禁用都是实时状态——用户在页面上一点，结果就变了。 所以这类选择器不要只查一次存起来，最好在事件回调里“当下再查一遍”，才能跟上用户的动作。

本式小结

  • jQuery 选择器与 CSS 同源，会 CSS 就掌握了它的大半；
  • 基本、组合、属性、位置、表单五大类选择器，按需取用；
  • $(selector).length 判断命中数量，命中 0 个也不报错；
  • 位置伪类是 jQuery 扩展，江湖上更推崇 .first()、.eq() 等方法；
  • :checked、:disabled 这类状态选择器要“现查现用”，别缓存太久。
