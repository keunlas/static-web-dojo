为什么是 jQuery

jQuery 诞生于 2006 年，曾是最流行的 JavaScript 库：它把浏览器之间不一致的细节抹平， 提供了一套极其简洁的 API。本教程使用的版本是 4.0.0。

如今原生 JavaScript 已经强大许多，但我们仍然推荐你学 jQuery，理由有三：

  • 存量项目遍地都是——无数网站、后台系统、WordPress 插件仍在用它，会 jQuery 才能维护它们；
  • 它是理解 DOM 的绝佳桥梁——jQuery 的“选择器”与 CSS 选择器一一对应，学一遍等于把 DOM 的核心概念重新嚼碎；
  • 写起来真的爽——链式调用、隐式遍历，几行代码能顶原生十几行。
心法：jQuery 与 Bootstrap 互不需要

正如第二回第一式所说，Bootstrap 5 不依赖 jQuery；反过来，jQuery 也不依赖 Bootstrap。 它们一个是“样式与组件库”，一个是“DOM 操作库”，各司其职。本回最后一式，我们会让两者合璧。

引入本地文件

jQuery 只有一个文件：jquery-4.0.0.min.js（min 表示压缩版，用于生产环境； 开发学习想读源码的话可以用未压缩版 jquery-4.0.0.js）。 同样放在 </body> 之前，并且必须排在你自己的脚本之前—— 因为你的脚本要使用 $，就得等它先登场。

认识 $(document).ready

还记得上一回的思考题吗？“脚本放在 <head> 里会找不到元素”。 jQuery 提供了一个更优雅的解法——就绪事件：把代码交给它， 等整个页面解析完毕后再执行，脚本从此可以放心地放在任何位置。

两个小知识：

  • “就绪”指的是 DOM 树解析完成，不一定等图片全部加载完——所以页面秒开，交互先行；
  • $ 就是 jQuery 的别名，两者完全等价，写哪个都行。

拆解这两行代码：

  • $('#btn-hello')——用选择器 #btn-hello（即 id 为 btn-hello 的元素）找到按钮；
  • .on('click', fn)——给它绑定点击事件，点击时执行后面的函数；
  • $('#msg-hello').text('……')——找到段落，把它的文字替换成新内容。
心法：链式调用

jQuery 的大多数方法都会返回“自己”，因此可以把操作串成一条链，例如 $('#btn-hello').addClass('btn-lg').text('换件衣裳')—— 同一行里先加大号样式、再改文字。第四式讲样式操作时，你会越来越喜欢这种写法。

效果完全一致。养成习惯：自己的脚本整体包在 $(function () { … }) 里， 就再也不用操心脚本位置与加载顺序的问题。

本式小结

  • jQuery 是一柄轻剑：用选择器找元素，用方法操作元素；
  • 引入时先 jQuery、后自己的脚本，放在 </body> 之前；
  • $(function () { … }) 是就绪事件的简写，也是今后每页代码的“标准外套”。
