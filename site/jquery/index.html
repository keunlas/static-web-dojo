如果说 Bootstrap 是重剑无锋，那 jQuery 就是一柄轻剑—— 它让“找到元素、操作元素”这件 JavaScript 里最琐碎的事，变得干净利落。

虽然如今原生 JavaScript 已经进步很多，但 jQuery 依然活跃在无数存量项目与插件生态中； 更重要的是，它的思路是理解 DOM 的绝佳桥梁。本回使用 jQuery 4.0.0， 本地引入、离线修炼，最后一式把它与 Bootstrap 合璧，写一个待办清单。

修炼建议

jQuery 的招式必须动手才有感觉：每式演示里的按钮，都请亲手点一点； 练功题更要自己敲代码。敲错了不丢人——报错信息是浏览器在给你指点迷津。
