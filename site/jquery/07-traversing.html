元素的家族关系

把页面看成一张家谱——每个标签都是某个标签的子嗣。按钮小友的一家，长这样：

document
└── html
    ├── head
    └── body
        ├── header
        └── main
            ├── h2（标题）
            ├── .card（第一张）── siblings：互为兄弟
            │   └── button（点我）← 你在这里
            ├── .card（第二张）── next() / prev()：同级的前后邻居
            └── p（段落）

围绕这张家谱，jQuery 准备了一组“认亲”方法：

方法家族说法找谁
parent()找父亲上一级父元素，只找一层
parents()列祖列宗所有祖先；可传选择器过滤，如 parents('.page')
children()亲儿子直接子元素；可传选择器过滤
find()满门子孙所有后代；必须传选择器，如 find('a')
siblings()兄弟姐妹同级全部；可传选择器过滤
next() / prev()紧邻的弟与兄后一个 / 前一个同级元素，各只找一个
closest()一路向上寻亲从自己开始向上，找最近的匹配；必须传选择器，可能命中自己

向上找：parent / parents / closest

parent() 只找上一级；parents() 把一路向上的祖先全部找来（可传选择器过滤）； closest(选择器) 从自己开始向上，返回最近的一个匹配。 最后一个正是事件委托的黄金搭档——事件绑在父级上，处理时却要操作“所在的那张卡片”，一记 closest 就位。

兄弟姐妹：siblings / next / prev

同级之间也有讲究：siblings() 把兄弟姐妹一网打尽（可传选择器过滤）， next() / prev() 只找紧挨着的后一个 / 前一个。

逐个点名：each()

jQuery 对选中集合的隐式遍历是“一声令下，全员行动”。可有些活儿必须逐个点名—— 比如“隔一行染一色”，得知道每个元素排第几。这时请 each() 出场：

缩小包围圈：filter / first / last / eq

选中一堆元素后，还可以从中再挑：first() 取第一个、last() 取最后一个、 eq(2) 取序号为 2 的那一个（即第三个，从 0 数）、filter() 按选择器或函数筛选。

心法：回顾隐式遍历

第一式就见过它：$('p').css('color', 'red') 会让所有段落变红。 隐式遍历是 jQuery 的默认性格——“对选中的每个元素都动手”；而本式的遍历方法负责“换个圈子再动手”。 位置伪类 :first / :last 在 jQuery 4 里仍然可用，但方法版 .first() / .last() 更清晰、也更快——官方推荐日常改用方法版。

再认几门亲戚：not / is / has 与 Until 系列

除了“往上找、往下找、找兄弟”，jQuery 还备了几个更聪明的问法： not() 是“排除掉某些”，is() 是“判断是不是”（返回 true / false， 不返回集合），has() 是“谁的子孙里有它”。

contents()连文本节点、注释节点也一并取出（主要在 iframe 场景用）集合

  3. 思考题：parents('.card') 与 closest('.card') 有什么区别？
参考答案 1

“先全局清洗、再局部点亮”是做“唯一选中”的常见套路； closest 负责把按钮的点击翻译成“所在卡片”的操作。

参考答案 2

closest 向上找到卡片、find 向下找到标题—— 上上下下的配合，正是遍历方法的日常。

参考答案 3

parents() 返回所有匹配的祖先（不含自己，可能有多个，由近及远排列）； closest() 从自己开始向上，返回最近的一个匹配（结果零个或一个）。 例 1 里两者都能找到卡片；但如果按钮自己也带 .card 类， closest 会返回按钮本身，而 parents 不会。找全部用 parents，找最近用 closest。

本式小结

  • 元素是一棵树：parent / parents / children / find 上下认亲，siblings / next / prev 同级走动；
  • closest 从自己向上找最近匹配，是事件委托的黄金搭档；
  • each(function (index, element)) 逐个点名，index 从 0 起，element 就是 this；
  • filter / first / last / eq 缩小包围圈；隐式遍历是“对每个选中元素都动手”的默认行为；
  • not 排除、is 判断（返回布尔值）、has 找“子孙里有的”；nextUntil / prevUntil / parentsUntil 走到谁为止（不含终点）；
  • addBack() 把起点或上一环并回来，add() 并入另一批元素。
