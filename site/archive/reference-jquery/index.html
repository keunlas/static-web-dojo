轻剑招式繁多，记不全很正常。这一页把 jQuery 的常用方法与选择器按类别摊开—— 每行一句话说明，附“学在哪一式”的指路牌。翻到即用，离线可查。

使用说明
  • 本页以本站携带的 jQuery 4.0.0 为准，收编的方法均经实测； “第 X 式”指第三回 jQuery 篇的章节；
  • 写法约定：实例方法写作 $el.方法()，静态工具写作 $.方法()；
  • 被移除的老方法、仍在但已弃用的方法单独列在页面末尾——“不能用”与“不推荐”是两回事。

选择器

写法说明学在哪
$('#id') / $('.class') / $('tag') / $('*')基本四式：按 id / 类 / 标签 / 全部第二式
$('div.card') / $('#a .b') / $('#a > .b') / $('h2, h3')组合：交集、后代、子代、逗号并集第二式
$('[type="text"]') / $('[href^="https"]') / $('[data-x]')属性：等于 / 前缀 ^= / 后缀 $= / 包含 *= / 存在第二式
:first :last :even :odd :eq(n) :lt(n) :gt(n) :nth(n)位置伪类（jQuery 扩展，4.0 中仍可用；日常推荐方法版 .first()/.eq()）第二式
:input :text :password :checkbox :radio :submit :file表单：按控件类型点名第二式
:checked :selected :disabled :enabled表单状态：勾选 / 下拉选中 / 禁用 / 可用（实时状态，现查现用）第二式

内容、属性与数据

方法说明学在哪
.text(值) / .html(值)读写文本（安全）/ 读写 HTML（传入用户输入要当心）第三式
.val(值)读写表单控件的值（input / select / textarea）第三式
.attr(名, 值) / .removeAttr(名)读写 HTML 属性（href、title、data-*…）第三式
.prop(名, 值) / .removeProp(名)读写“状态属性”（checked、disabled、selected）第三式
.data(名, 值) / .removeData(名)在元素上挂运行时数据（任意 JS 值，不写入 HTML）第十二式
.css(属性, 值)读写行内样式；读回的是计算后的像素值第四式

事件

写法说明学在哪
.on('click', 函数) / .off('click')绑定 / 解绑（事件名的统一入口）第五式

.one('click', 函数)只响应一次，之后自动解绑第五式
.trigger('事件名') / .triggerHandler('事件名')主动触发（含默认行为）/ 只跑处理函数第五式
.hover(进入, 离开)mouseenter + mouseleave 的快捷写法（自 jQuery 3.3 起弃用，新代码请用 on() 分别绑定）第五式

事件名（部分）click dblclick mouseenter mouseleave mousemove keydown keyup submit change input focus blur scroll resize第五式
事件对象e.preventDefault() 拦默认行为、e.stopPropagation() 截冒泡、e.stopImmediatePropagation() 连同级后续处理函数一并拦下、e.target 事件源头第五式

jQuery 4.0 的移除与弃用清单

这一节请务必看清——它区分了“已经不存在”和“还在但不推荐”两件事：

状态成员替代写法
已移除（调用即报错） $.trim()、$.parseJSON()、$.now() s.trim()、JSON.parse()、Date.now()
$.type()、$.isArray()、$.isFunction()、$.isNumeric()、$.isWindow()、$.nodeName()、$.camelCase()、.live()、.die() typeof / Array.isArray() / 原生判断；事件用 on() / off()
仍在、已弃用 .bind()、.unbind()、.delegate()、.undelegate()、.hover()、$.proxy() on() / off()、原生 Function#bind——功能还能用，但写新代码就用新写法
心法：版本事实以源码与实测为准

网上不少文章把“弃用”说成“移除”，也有的把“仍然可用”写成“早就没了”。 本站本页的结论全部对照仓库内 reference/jquery/jquery-4.0.0.js 源码并在浏览器中实测过—— 遇到分歧，认源码，别认传闻。

一句话记忆

选择器找对象，遍历换圈子，text / html / val 管内容，attr / prop / data 管属性与数据； on / off 管事件，fade / slide / animate 管动画，$el.load / $.get / $.getJSON 管取数， $.* 是工具箱。链子断了找 .end()，忘了怎么写——回这一页。
