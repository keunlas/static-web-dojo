类名繁多，不必都记在脑子里——记在心里，查在指间。这一页是本站教程里出现过（以及相关） 的工具类速查：每个取值一句话说明，翻到即用。

使用说明
  • * 表示占位符：间距类写数字 0–5，颜色类写 8 色名，断点类写 sm / md / lg / xl / xxl；
  • 带断点的类（如 mt-md-3、d-lg-none）除专门标注外，一律遵循 “该断点及以上生效”；
  • 完整组件（卡片、导航、模态框等）请查离线文档； 本页只收“一招一式”的工具类。

水平对齐：justify-content-*

作用于弹性容器（row、d-flex 等），决定“多余空间怎么分”。

类名效果
justify-content-start列挤在行首（默认行为）
justify-content-center列整体居中，最常用
justify-content-end列挤到行尾
justify-content-between两端贴边，列与列之间均分
justify-content-around每个列左右各分半份，列间缝是边缘缝的两倍
justify-content-evenly列与列、列与边缘的缝全部相等

带断点：justify-content-md-center 等，从该断点起生效。

垂直对齐：align-items-* / align-self-*

类名效果
align-items-start子项顶端对齐
align-items-center子项垂直居中
align-items-end子项底端对齐
align-items-stretch拉伸撑满（默认行为）
align-items-baseline按文字基线对齐
align-self-*同上五个取值，但只作用于单个子项
align-content-*弹性容器换行后行与行之间的分布，取值同 justify-content

20.5rem（8px）小间隔
31rem（16px）标准间距
41.5rem（24px）宽松
53rem（48px）大开大合
方向后缀作用例子
t 上 / b 下 / s 左 / e 右单边mt-3 上边距 1rem

颜色：text-* / bg-* / text-bg-*

8 色语义贯穿全站：primary 主、secondary 次、success 成、danger 危、warning 警、info 讯、light 浅、dark 深。

类名效果
text-primary 等文字色（本站主色已被染成朱砂）
bg-primary 等背景色
text-bg-primary 等背景 + 自动配好对比文字色
primary-subtle 等柔和版（如 bg-primary-subtle），做浅底醒目不易翻车
text-primary-emphasis 等强调版文字色

border-primary 等边框颜色

显示：d-*

值有多少种，类就有多少种；每种都能加断点前缀（如 d-md-none）。

值作用
d-none隐藏（最常用的“开关”起点）
d-inline / d-inline-block行内 / 行内块
d-block块级、独占一行
d-flex / d-inline-flex弹性布局（配合下文 flex-*）
d-grid网格布局
d-table / d-table-row / d-table-cell用 CSS 扮演表格结构
心法：显隐开关

d-none d-md-block = 默认隐藏、md 起显示；d-md-none = 默认显示、md 起隐藏。 注意显隐类只管视觉，内容仍在 HTML 里，读屏软件照样能读到。

弹性布局：flex-* 与 gap-*

类名效果
flex-row / flex-row-reverse横向排（默认）/ 横向反排
flex-column / flex-column-reverse纵向排 / 纵向反排
flex-wrap / flex-nowrap / flex-wrap-reverse允许换行（默认）/ 禁止换行 / 反向换行
flex-fill等分剩余空间（想平均分就用它）
flex-grow-0/1按比例抢占剩余空间（0 不抢）
flex-shrink-0/1空间不足时是否可压缩（0 不缩）
order-0 – order-5，另有 order-first / order-last视觉排序，数字小在前
gap-0 – gap-5（可加断点如 gap-lg-3）子项之间的横纵向间距

尺寸：w-* / h-*

类名效果
w-25 / w-50 / w-75 / w-100 / w-auto宽度 25% / 50% / 75% / 100% / 按内容
h-25 / h-50 / h-75 / h-100 / h-auto高度同款五档
mw-100 / mh-100最大宽 / 最大高 100%
vw-100 / vh-100视口宽 / 高的 100%

位置与层级：position-* / top-* / start-*

类名效果
position-static / -relative / -absolute / -fixed / -sticky默认 / 相对 / 绝对 / 固定 / 吸顶
top-0/50/100、bottom-0/50/100、start-0/50/100、end-0/50/100相对定位容器四边的偏移距离
translate-middle / -x / -y自身平移 50%（配合 top-50 等实现精确居中）

可见性、透明度与交互

类名效果
visible / invisible可见 / 隐藏但仍占位（区别于 d-none）
opacity-0 – opacity-100透明度 5 档（0 / 25 / 50 / 75 / 100）
overflow-auto / overflow-hidden溢出滚动 / 溢出裁剪（另有 overflow-scroll / overflow-visible）
user-select-all / -auto / -none整段一键选 / 正常 / 禁选
pe-auto / pe-none指针事件放行 / 穿透（禁点常用）
一句话记忆

栅格管布局、间距管呼吸、文本管脸面、颜色管情绪； 方向后缀 t/b/s/e/x/y 记一次，断点前缀 sm/md/lg/xl/xxl 记一次， 剩下的组合拳，怕忘就来翻这一页。
