纯静态网页的修行

不修仙，不炼丹。一行一行写页面，把网页的基本功练扎实。

开始修行 直接进入 Bootstrap 篇

这是什么

这是一份关于纯静态网页的修行手册。在这里，我们只使用最朴素的三样工具—— HTML 搭建骨架、CSS 披上外衣、JavaScript 赋予灵魂； 并借助两位江湖前辈——Bootstrap 让布局与组件信手拈来，jQuery 让 DOM 操作化繁为简。

完全离线可用

所有样式、脚本、字体与文档都在站内，下载到本地双击即可阅读，不依赖任何互联网资源。

零构建工具

不需要 npm、不需要打包器，一个文本编辑器 + 一个浏览器，就是全部装备。

藏经阁内置

Bootstrap 完整离线文档与官方示例集随站携带，查阅文档无需联网。

每式必有练功

每章都有现场演示与练习，看十遍不如写一遍。

四十三式，从 HTML 骨架到 CSS 布局再到 JavaScript 交互：从零讲起，读完还能当字典查。

怎么用这个站

第一次来，不必从中间跳着看。按下面的节奏走，前三回读完，你就能独立写出一个像样的静态页面； 之后把第四回当字典，随用随查。

  • 阅读顺序：第一回打基础（HTML → CSS → JavaScript）→ 第二回 Bootstrap 十八式 → 第三回 jQuery 十四式 → 第四回藏经阁随查随用；每一回都按顺序读，效果最好。
  • 每章怎么读：先用“本式要点”看全局，再跟着“现场演示”把例子点一遍； 每个演示上方是可运行的效果、下方是它的源码——源码可以照着抄、直接改； 读完做“练功”巩固，最后看“本式小结”。
  • 记不住类名和方法？用顶栏的搜索框（按 / 聚焦）； 或直接翻工具类速查与 jQuery 方法速查两页字典。
  • 想马上试手：打开练功场， HTML / CSS / JS 三栏随便写，预览即时刷新。
  • 想查原始资料：第四回藏着 Bootstrap 的完整离线文档、官方示例集与 2000+ 个图标；断网也能翻。
  • 想离线带走：把整个仓库下载到本地，双击 site/index.html 即可阅读 （唯一例外是 jQuery 第九式 Ajax，它需要本地服务器，章节内有说明）。

开始之前

你只需要三样东西：

  • 一个文本编辑器（推荐 VS Code）
  • 一个现代浏览器（Chrome / Edge / Firefox 均可）
  • 一颗愿意慢慢练习的心
本手册的边界

本教程刻意保持“纯粹”，不涉及 React / Vue 等现代框架、Webpack / Vite 等构建工具、Node.js 后端与 TypeScript。我们相信：把基本功练扎实，比急着上框架更重要。

修行没有捷径，但每写一行，你就离“会写网页”更近一步。
