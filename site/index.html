纯静态网页的修行

不修仙，不炼丹。一行一行写页面，把网页的基本功练扎实。

开始修行 直接进入 Bootstrap 篇

这是什么

这是一份关于纯静态网页的修行手册。在这里，我们只使用最朴素的三样工具—— HTML 搭建骨架、CSS 披上外衣、JavaScript 赋予灵魂； 并借助两位江湖前辈——Bootstrap 让布局与组件信手拈来，jQuery 让 DOM 操作化繁为简。

完全离线可用

所有样式、脚本、字体与文档都在站内，下载到本地双击即可阅读，不依赖任何互联网资源。

零构建工具

不需要 npm、不需要打包器，一个文本编辑器 + 一个浏览器，就是全部装备。

藏经阁内置

Bootstrap 完整离线文档与官方示例集随站携带，查阅文档无需联网。

每式必有练功

每章都有现场演示与练习，看十遍不如写一遍。

开始之前

你只需要三样东西：

  • 一个文本编辑器（推荐 VS Code）
  • 一个现代浏览器（Chrome / Edge / Firefox 均可）
  • 一颗愿意慢慢练习的心
本手册的边界

本教程刻意保持“纯粹”，不涉及 React / Vue 等现代框架、Webpack / Vite 等构建工具、Node.js 后端与 TypeScript。我们相信：把基本功练扎实，比急着上框架更重要。

修行没有捷径，但每写一行，你就离“会写网页”更近一步。
