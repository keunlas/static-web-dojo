## 本批完成的事

**`site/basics/22-css-grid.html` Grid 网格布局**（5 个演示 + 3 道练功）：

- 心智模型：网格线（从 1 数、负数从末尾数）、轨道、单元格；显式网格 vs 隐式网格
  （<code>grid-auto-rows</code> / <code>grid-auto-columns</code>）+ 例 1 三列两行基础网格；
- 列宽写法表：<code>1fr 1fr 1fr</code> / <code>repeat(3, 1fr)</code> / <code>200px 1fr</code> /
  <code>minmax(200px, 1fr)</code> / <code>repeat(auto-fit, minmax(200px, 1fr))</code> /
  <code>auto-fill</code>，并点出 <code>1fr</code> 最小值是 auto 的坑（长内容撑破，写
  <code>minmax(0, 1fr)</code> 可治）；
- 例 2：自适应卡片墙，脚本在 <code>DOJO.ready</code> 后量一次、并在 <code>resize</code>
  时重新量，实时报告“每列约多少 px、一行放几列”；
- 定位写法表（<code>grid-column: 1 / 3</code>、<code>2 / -1</code>、<code>span 2</code>、
  <code>grid-area: 3 / 3</code>、命名区域）+ 例 3 跨格（标题 span 3、侧栏 row span 2、点名站位）；
- <code>grid-template-areas</code> 的 ASCII 画图法 + 例 4 整页骨架
  （head / side / main / foot 三行两列）；
- 对齐三层表（<code>*-items</code> / <code>*-self</code> / <code>*-content</code>）
  + 例 5：<code>place-items: center</code>、单个项目 <code>place-self: stretch</code>、
  以及**两个项目写同一格形成叠加层**；
- 常见套路表（等宽三列 / 自适应卡片墙 / 固定侧栏 + 自适应主栏 / 整页骨架 /
  <code>grid-auto-rows: minmax(80px, auto)</code> / 覆盖层）与
  「一维 Flex、二维 Grid、两者嵌套」的选择标准。

## 本批的两处“实测校准”

1. **叠加层要真的叠上**：例 5 初版把两个项目分别放在格子的左下与右上，
   实测 `overlap: false`——它们在同一格里却互不覆盖，演示名不副实。
   改成“底层 <code>place-self: stretch</code>（像一张图）+ 上层 <code>place-self: end start</code>
   （像图上的一行说明）”，复测 `overlap: true`、`overInsideUnder: true`。
2. **实时数字要在布局稳定后再量**：例 2 初版脚本在页面解析时立刻量宽，
   拿到的是站点注入侧栏/TOC 之前的旧值（写着 242px，实际已是 152px）。
   改为 `DOJO.ready(report)` 先量一次、`window.addEventListener('resize', report)`
   跟随变化，复测文案与实测一致（152px / 5 列）。
