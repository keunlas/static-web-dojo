**`site/basics/33-js-objects.html` 对象与 Map/Set**（5 个演示 + 3 道练功）：

- 创建对象的四种写法（字面量 / 简写属性 / 计算属性名 / <code>Object.fromEntries</code>）
  与读写表（点号 vs 方括号、<code>in</code> 与 <code>Object.hasOwn</code> 的差别、
  <code>delete</code>、越界得 undefined、可选链）；
- 例 1：读写的现场 + **方法里的 this**（对象调用正常；把方法摘出来单独调用，
  严格模式下 <code>this</code> 是 undefined，于是抛出
  <code>TypeError: Cannot read properties of undefined</code>，用 try/catch 抓出来展示）
  + <code>toString</code> 在 <code>in</code> 里为 true 而在 <code>Object.hasOwn</code> 里为 false
  （原型链的直观证据）；
- 解构与展开：改名、默认值、嵌套、剩余属性、复制与合并；
  例 2 **浅复制现场**：改副本顶层不影响原对象，但改副本的嵌套对象会“连坐”，
  换成 <code>structuredClone</code> 才彻底独立；
- <code>Object</code> 静态方法速查表（keys/values/entries/fromEntries/assign/hasOwn/
  freeze/isFrozen/seal）+ 例 3：entries+map+fromEntries 做“分数翻倍 / 只留及格项”，
  以及冻结对象后赋值抛 <code>TypeError: Cannot assign to read only property</code>；
- <code>Map</code> / <code>Set</code> 与对象的对照表（键的类型 / size / 遍历顺序 / 用途）
  + 例 4：Map 统计词频（<code>set(w, (get(w) || 0) + 1)</code>）、
  **用对象当键**（换一个长得一样的对象查不到——引用相等）、Set 去重、
  <code>[...new Set(arr)]</code> 最简去重、并集 / 交集 / 差集手写三连；
- <code>WeakMap</code> / <code>WeakSet</code> 的一句话定位（弱引用、不可遍历、无 size）；
- JSON：例 5 把 <code>stringify</code> / <code>parse</code> 的边界一次演完——
  函数与 undefined 被丢弃、<code>NaN</code> 变 <code>null</code>、
  日期变 ISO 字符串、数组里的空位变 <code>null</code>、循环引用抛 <code>TypeError</code>、
  非法 JSON 抛 <code>SyntaxError</code>（都用 try/catch 接住）；
  并给出 <code>JSON.stringify(obj, null, 2)</code> 的调试技巧。
