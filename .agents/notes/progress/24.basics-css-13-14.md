## 写法沉淀（CSS 章节的演示约定）

- **演示样式一律用演示专属 id 作用域**（如 `#css14-demo3 .ledger th`），
  否则 `<style>` 是全局的，会污染整页；这一条在 `conventions.md` §3.1 已有规定，本批首次大规模实践；
- **每条规则都要在演示里真实生效**：本轮自查时发现例 2 原写的 `[href$=".pdf"]` 规则
  没有任何 `.pdf` 链接可命中，改成 `[href$=".mp3"]` 后规则与效果一一对应
  （写 CSS 演示要把“规则—效果”的对应当成硬指标）；
- 颜色尽量取站内纸墨变量或明确的浅底/深字配对，保证明暗两种主题下都看得清。
