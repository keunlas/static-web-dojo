### 2. 审计中查出并补掉的三个内容缺口

审计方式是“拿关键字扫全篇”：
`history.pushState`、`AbortController`、`Element.animate()`、`clipboard`、
`ResizeObserver`、`MutationObserver`、`requestIdleCallback`、`IndexedDB`、`cookie`
逐条 grep，再判断“该不该讲”。结论：三个该讲没讲，当场补上。

1. **39 式补 <code>AbortController</code>**：全篇此前只有“定时器能取消”，
   没有任何一处讲“已经发出去的请求怎么取消”。补一段可直接抄的
   <code>signal</code> + <code>abort()</code> 代码（含 <code>AbortError</code> 判断与
   “其他错误照旧往上抛”），并回指第三十八式的防抖搜索
   （旧结果晚到会覆盖新结果）——这正是新手写搜索框迟早要踩的坑。
2. **40 式补 <code>history.pushState</code>**：原来表格里只有一行「前进 / 后退」。
   补一段用法代码 + 一个警示框。**表述以实测为准**：先怀疑“file:// 下会跳到不存在的文件”，
   于是用 CDP 在 file:// 页面实测——真实结果是<strong>直接抛 <code>SecurityError</code></strong>
   （<code>origin 'null'</code> 不允许造 <code>file:///tmp</code> 这样的地址），
   而 <code>"#dummy"</code> 这样的锚点正常。正文按实测写，并注明实测环境。
3. **41 式补 <code>Element.animate()</code>（Web Animations API）**：
   全文此前没有任何“用 JS 写动画”的正门，而它与第二十四式的动画概念一一对应。
   补一段带特性检测与降级的代码，并给出分工结论
   （参数要由 JS 算出来时用它；纯装饰动画仍写在 CSS 里）。

### 4. 顺手修掉一个“工具自伤”的坑（不影响站点，影响后续每个代理）

审验过程中 CDP 工具卡住，我用 `pkill -f 'cdp-eval.js'` 去清理进程，结果命令自己
以退出码 143 中断、后面的步骤全没跑。根因是 `pkill -f` 匹配**整个命令行**，
而执行这条命令的 shell 自己的命令行里也含 `cdp-eval.js` 这个子串。
已按模板归档为 `bug-fix/pkill-f-kills-own-shell.md`（含复现方法与
`pgrep → ps → kill <PID>` 的正确姿势），并同步更新
`bug-fix/README.md` 索引与 `skills/verify-offline/SKILL.md` 的清理说明。
