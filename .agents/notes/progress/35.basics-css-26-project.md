## 本批的“结构一致性”打磨（值得记一笔）

最初那版成品页里，我为了排版顺手加了几样东西：外层 <code>div.page</code>、表单字段的
<code>div.field</code> 包装、给卡片加的 <code>tabindex="0"</code>、把 <code>mark</code> 换成
<code>span class="tag"</code>、外加一段“本站首页”的段落与改写的页脚文案。
写验收清单时意识到：这样一来「<strong>结构一行没动</strong>」就成了不实之词。
于是逐项改回：

- 用 <code>body</code> 直接当网格容器与限宽容器 → 去掉 <code>div.page</code>；
- 表单字段保留原来的 <code>&lt;p&gt;</code> 与 <code>&lt;br&gt;</code> → 去掉包装 div；
- 卡片去掉 <code>tabindex</code>（它不是交互元素，靠 <code>:focus-within</code> 反馈就够）；
- 标签继续用 <code>mark</code>（保留语义），只是把它样式化成胶囊；
- 段落与页脚文案回归原样，仅保留页脚那一句“手写 HTML 与 CSS”的措辞调整。

**验证方式**：用 CDP 各自取出两页 <code>body</code> 内所有元素的标签序列并逐字比对——
结果为「标签序列一致: True」；文本开头也一致，全文差异只有页脚那一句。
这样正文里那句“用脚本逐节点比对过”是有据可查的。
