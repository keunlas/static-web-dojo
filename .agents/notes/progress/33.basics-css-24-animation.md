## 本批完成的事

**`site/basics/24-css-transition-animation.html` 过渡、变形与动画**（5 个演示 + 3 道练功）：

- <code>transition</code> 四件套表（property / duration / timing-function / delay）
  + “简写里第一个时间是时长、第二个是延迟”的提醒 + “哪些属性可过渡”的说明；
- 例 1 三个按钮只有时长不同（0.08s / 0.25s / 0.9s），并同时支持
  <code>:hover</code> 与 <code>:focus-visible</code>（键盘读者也有反馈）；
- 缓动函数表（linear / ease / ease-out / ease-in / ease-in-out / cubic-bezier / steps）
  + 例 2 **五条轨道同时起跑**：鼠标移进虚线框，五个色块用五种节奏同时移动，
  差异一眼可见（移出后按同样规律返回）；
- <code>transform</code> 家族表（translate / scale / rotate / skew / transform-origin）
  + 例 3 四个方块分别演示上浮、放大、旋转、倾斜，再加一个组合动作；
  正文强调**多个变换从左到右生效、顺序会影响结果**，并提醒 <code>transform</code>
  会创建层叠上下文（与第二十式呼应）；
- 例 4 实战套路：卡片悬停“上浮 + 阴影加深 + 封面缓放大”，并解释为什么只动
  <code>transform</code> 与颜色类属性；
- <code>@keyframes</code> 写法（from/to 与百分比）与 <code>animation</code> 子属性表
  （name / duration / iteration-count / direction / fill-mode / play-state / delay）；
- 例 5 两个小动画：转圈的加载指示（<code>linear infinite</code>）与呼吸徽章（0% / 50% / 100%），
  并内建 <code>@media (prefers-reduced-motion: reduce)</code> 降级；加载指示带
  <code>role="status"</code> 与 <code>aria-label</code>，示范“动效不能是唯一的信息渠道”；
- 性能与体验三条底线表（优先动 transform/opacity、照顾 prefers-reduced-motion、
  动效不承担唯一信息）+ DevTools 的 Animations 面板慢放技巧。
