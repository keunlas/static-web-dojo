## 本批的实测与踩坑

- **例 4 的层叠验证需要滚动到视口内**：`elementFromPoint` 只对当前视口有效，
  第一次断言在页面长距离之外取点，返回 `null`。
- **还踩到本站自己的 `html { scroll-behavior: smooth }`**：`scrollIntoView()` 是动画滚动，
  紧接取坐标仍是途中值。改用 `document.documentElement.style.scrollBehavior = 'auto'`
  + `window.scrollTo(0, 绝对坐标)` + `requestAnimationFrame` 后，
  实测得 `topAtOverlap: "other"`、`topAtInnerCenter: "other"`——
  红色块（z-index 2）确实压住了那个写着 9999 的子元素。
  这条已写进 `skills/verify-offline/SKILL.md` 的常见失败对照表。
