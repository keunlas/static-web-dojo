## 本批完成的事

**`site/basics/39-js-async.html` 异步**（4 个演示 + 3 道练功 + 3 个结构块）：

- 「同步与异步」：把“页面为什么不能站着等”说清——慢活儿交出去、登记回调、自己接着跑；
  心法一句“异步不是同时干两件事的魔法，而是先记下这事、别堵住后面”；
- 「定时器」：<code>setTimeout</code> / <code>setInterval</code> /
  <code>requestAnimationFrame</code> 速查表（含各自的取消方式）+
  两个必须记住的事实（毫秒只是“至少等这么久”、定时器不保证顺序）；
  **例 1** 是执行顺序的实证：三行同步代码 → 微任务 <code>Promise.then</code> →
  宏任务 <code>setTimeout(…, 0)</code>；
- **例 2** 倒计时：<code>setInterval</code> 每 100ms 减 0.1，
  到点自己 <code>clearInterval</code>，中途可「取消」并如实报出停在第几秒
  （实测：1 秒时 4.0 → 取消后 0.4 秒仍停在 4.0）；
- 「Promise」：三态（等待中 → 兑现 / 拒绝，只变一次）+ <code>.then/.catch/.finally</code>
  的结构块 + 四个组合方法对照表（all / allSettled / race / any 各自什么时候给结果、适合什么）；
  **例 3**：同样三件假活儿（400 / 300 / 200 ms），
  串行实测 **901 ms**、<code>Promise.all</code> 实测 **400 ms**，
  把“等三段相加”与“只等最慢那段”的差别直接摆出来；
- 「async / await」：同一件事的 <code>.then</code> 版与 <code>await</code> 版并排结构块 +
  两个要点（async 函数总返回 Promise；<code>await</code> 只能写在 async 函数或模块顶层）；
  **例 4** 用 <code>async</code> 函数走完整轨迹：<code>await</code> 拿到成功结果 →
  下一步拒绝被 <code>try/catch</code> 接住 → <code>finally</code> 照走 →
  <code>Promise.allSettled</code> 逐条汇报 <code>fulfilled</code> / <code>rejected</code>；
- 「事件循环」：两条队列的结构块 + 四条问答表（0 毫秒定时器为什么不是立刻、
  <code>.then</code> 为什么排在定时器前、定时器准不准、长循环为什么卡页面）；
- 本式小结六条 + 练功三题（可取消的三秒提示、<code>delay(ms)</code> 与
  <code>Promise.all</code> 实测总耗时、思考死循环十秒里浏览器发生了什么）。
