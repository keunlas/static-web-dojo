## 本批完成的事

**`site/basics/29-js-operators.html` 运算符与表达式**（5 个演示 + 3 道练功）：

- 算术运算符表 + 三个特殊结果（<code>1 / 0</code> → Infinity、<code>0 / 0</code> → NaN、
  NaN 会“传染”）+ 自增前置后置的差别 + 复合赋值；
- 「两个加号」：<code>+</code> 的双重身份（有字符串就拼接），
  例 1 用 11 行实测表把“奇怪但正确”的结果摆出来
  （<code>"1" + 1</code> → <code>"11"</code>、<code>1 + true</code> → <code>2</code>、
  <code>"3" * "4"</code> → <code>12</code>）；
- 比较运算符表（<code>===</code> / <code>==</code> / <code>Object.is</code>）+ 例 2
  **七组对照**（<code>0 == ""</code>、<code>0 == false</code>、<code>null == undefined</code>、
  <code>NaN === NaN</code>、<code>[] == false</code>…），并点明唯一惯用例外 <code>x == null</code>；
- 「两个怪脾气」提醒：<code>null &gt; 0</code> 为 false 而 <code>null &gt;= 0</code> 为 true；
  NaN 与任何值比较都是 false；
- 逻辑运算符表（<code>&amp;&amp;</code> / <code>||</code> / <code>!</code> / <code>!!</code>，
  强调“返回操作数本身”与短路）+ 例 3 十一行口诀表
  （含 <code>0 || "兜底"</code>、<code>0 ?? "兜底"</code>、<code>"" || "x"</code> 与
  <code>"" ?? "x"</code> 的对照，以及用副作用计数证明短路确实没执行赋值）；
- <code>?.</code> 与 <code>??</code>：例 4 用“可能缺字段的用户数据”演示
  <code>?.prop</code>、<code>?.[0]</code>、<code>?.()</code> 与兜底组合，
  并提醒“<code>?.</code> 只保护它左边那一步”；
- 其它运算符速查表（三元、展开、<code>typeof</code>、<code>instanceof</code>、
  <code>in</code>、<code>delete</code>、<code>void</code>、位运算）；
- 优先级与结合性表（含 <code>**</code> 与赋值右结合）+ 例 5 现场：
  <code>2 ** 3 ** 2</code> → 512、<code>1 + 2 + "岁"</code> → <code>"3岁"</code>、
  <code>true || false &amp;&amp; false</code> → true，
  并用 <code>new Function()</code> 安全捕获“<code>??</code> 与 <code>||</code> 直接混用”的
  <code>SyntaxError: Unexpected token '||'</code>（语法错误无法用普通 try/catch 接住）。
