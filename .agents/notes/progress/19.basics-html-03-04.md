# 19 · 基础篇 03–04 式（列表与链接、图片）

> 来源：2026-09-14 同一轮工作（基础篇改版的第二批次）。正文原样归档，编号只增不改。

## 本批完成的事

1. **`site/basics/03-html-lists-links.html` 列表与链接**（4 个演示 + 3 道练功）：
   - 无序/有序列表与「容器只装 li」的硬规矩；嵌套列表与编号控制
     （`start` / `reversed` / `type` / `value` 属性表）；
   - 描述列表 `dl` / `dt` / `dd`（一个词配多条解释）；
   - 链接的四种去处（页面 / 锚点 / `mailto:` / `tel:`）、`target="_blank"` + `rel="noopener"`、
     `download` 属性、链接文字要自解释的心法；
   - 路径速查表（同目录 / `./` / `../` / 子目录 / 站点根 `/` 在 file:// 下不可用 / 绝对 URL）
     与「链接失效三步排查」。
2. **`site/basics/04-html-images.html` 图片**（3 个演示 + 3 道练功）：
   - `img` 属性表（`src` / `alt` / `width` / `height` / `loading="lazy"` / `decoding="async"`）；
   - `alt` 的三种写法（内容图 / 装饰图 `alt=""` / 链接图写“点了去哪”）与「不要把文字做成图片」；
   - 图片是行内元素、默认基线对齐 → 底部空隙现象（现场可见）；
   - `figure` + `figcaption` 图文配对；
   - 图片格式选择表（JPEG / PNG / GIF / WebP / AVIF / SVG）；
   - 响应式图片两套写法：`srcset` + `sizes`、`picture` + `source`（用**非演示的结构块**呈现，
     因为效果取决于视口与 DPR，小演示框里看不出来——这是本批确立的取舍）。
3. **site.js 登记 03、04 两式**（basics 回的 chapters 数组）。
4. **新工具两件**（tools/verify/）：
   - `cdp-shot.js`：整页截图，用于人工目检版式（本批用它检查了 02、03 两式的纸墨风呈现；
     截图存 /tmp，不入库）；
   - `cdp-eval.js` 增加 `VIEWPORT=宽x高` 环境变量（默认 1280×900），
     便于在 1600px 下断言右侧目录的布局。

## 约定沉淀

- **预览不了的 HTML 特性用非 .demo 结构块**：`head` 元数据、`tel:`/下载类链接、
  `srcset` / `picture` 这类效果依赖视口或 DPR 的写法，都用不带预览的
  `<script type="text/plain" data-lang="html">` 呈现（parity 检查不涉及它们）；
  这一条已写进 `conventions.md` §3.1 的语境里，后续章节照此办理。
