## 本批完成的事

**`site/basics/28-js-variables.html` 变量与数据类型**（5 个演示 + 3 道练功）：

- 声明与赋值、命名的硬规矩（字母/数字/<code>_</code>/<code>$</code>、不能数字开头、
  区分大小写、保留字）与软约定（驼峰、常量全大写、名字要能读出意思），
  外加一句“中文变量名合法但不要用”的提醒；
- <code>let</code> / <code>const</code> / <code>var</code> 对照表（作用域、能否重赋值、
  能否重复声明、声明前访问）+「默认 <code>const</code>，需要改再降级为 <code>let</code>」的理由；
  例 1 用块级作用域现场演示：<code>let</code> 出不了花括号、<code>var</code> 管不住自己、
  循环变量 <code>i</code> 出了循环就失效（全程用 <code>typeof</code> 探测，不报错）；
- 七种原始类型表 + <code>typeof</code> 速查表（含 <code>typeof null === "object"</code> 的历史遗留、
  数组要用 <code>Array.isArray()</code>、函数有“小灶”）；
  例 2 把十一种值依次 <code>typeof</code> 一遍，结果与表格逐行一致；
- 例 3 **原始值 vs 对象**：赋值与比较的差别（对象存的是“地址”，
  <code>{a:1} === {a:1}</code> 为 false 而同一个盒子自比为 true）+ 便签与地址的比喻
  + 「原始值永远不可变」的说明（<code>s[0] = "x"</code> 无效，严格模式下报错）；
- 真假值表（八个假值）+ 例 4 转换速查表（Boolean / Number / String 三列，含
  <code>"0"</code>、<code>" "</code>、<code>[]</code>、<code>{}</code> 这些反直觉项），
  以及三条纪律（别靠隐式转换、比较一律 <code>===</code>、转数字用 <code>Number()</code> /
  <code>parseInt(s, 10)</code>）；
- 例 5 模板字符串（插值 + 表达式 + 三元判断），并借机点出
  “用户输入不能塞进 <code>innerHTML</code>”（第三十七式细讲）。
