## 本批完成的事

**`site/basics/35-js-classes.html` 类与原型**（5 个演示 + 3 道练功）：

- 老写法：构造函数 + <code>new</code> 的四步（造对象 → 绑 this → 执行 → 返回对象）、
  方法挂在 <code>prototype</code> 上共享、原型链与 <code>instanceof</code>；
  例 1 实测：两个实例、<code>Object.hasOwn</code> 区分自有属性与原型方法、
  <code>a.greet === b.greet</code> 为 true、**改一次原型所有实例立刻跟着变**，
  并把原型链打印成「实例 a → Member.prototype → Object.prototype → null」；
- 新写法：<code>class</code> 全零件（<code>constructor</code>、方法、<code>get</code>/<code>set</code>、
  <code>static</code> 字段与方法、私有字段 <code>#</code>）；
  例 2 实测 getter/setter、静态成员只挂在类上（<code>t1.describe → undefined</code>）、
  私有字段从外部用字符串键读得到 <code>undefined</code>；
  正文点明「<code>t1.#secret</code> 是解析阶段就报的语法错误」；
- 提醒 class 与构造函数的三点不同（TDZ 不能提前用、不加 <code>new</code> 调用会报错、
  类体自动严格模式且方法不可枚举）；
- 继承：<code>extends</code> + <code>super()</code> + 重写 + <code>super.方法()</code>；
  例 3 实测父类实例没有子类方法、<code>instanceof</code> 沿链为 true、
  静态方法也被继承；并给出「组合往往优于继承」的经验；
- <code>call</code> / <code>apply</code> / <code>bind</code> 对照表 + 例 4 实测
  （借用方法、bind 固定 this 后仍能累加计数、方法摘出来单独调用抛
  <code>TypeError: Cannot read properties of undefined</code>、
  回调里 this 丢失与「用箭头函数包一层」的修法）；
- 例 5 综合演练：用 <code>class</code> 写一个待办清单（私有 <code>#items</code>、
  getter <code>size</code>/<code>remaining</code>、方法返回 <code>this</code> 支持链式调用），
  收束到「把数据与操作它的方法放在一起，并控制别人怎么碰它」。
