## 本批完成的事

**`site/basics/25-css-variables.html` CSS 变量与主题**（5 个演示 + 3 道练功）：

- 声明与取值（<code>--name: 值</code> / <code>var(--name)</code>）+ 与预处理器变量的三点不同
  （浏览器原生、参与层叠与继承、值可以是一整串）+ 命名两条硬规矩（必须 <code>--</code> 开头、区分大小写）；
- 例 1：定义一次多处使用（卡片/标签/按钮共用 <code>--brand</code>、<code>--card-radius</code>、<code>--card-gap</code>），
  实测变量值、取色、圆角、内边距全部对得上；
- 作用域与继承：例 2 用“局部变量”让同一个面板组件呈现三种性格
  （<code>--accent</code> / <code>--pad</code> 在子选择器里覆盖），并点出组件库里的术语 component token；
- 回退值写法 + 「回退值救不了值非法」的坑 + 例 3 三种情况对照
  （有变量 → 绿色；没变量 → 兜底朱砂；变量存在但值非法 → 整条声明作废、退回默认墨色）；
- 主题切换写法（<code>:root</code> 定义 + <code>[data-theme="dark"]</code> 整组覆盖）
  + 例 4 现场切换（脚本只改一个属性，底色/文字/强调色整组变）；
- 与 <code>calc()</code>、<code>repeat()</code>、媒体查询的配合（并明确“变量不能用在媒体查询的条件里”）；
- 例 5：JS 用 <code>setProperty('--scale', …)</code> 驱动多个属性（内边距、圆角、字号一起放大），
  为第三十七式的 DOM 篇留了接口；
- 进阶点：变量不能当属性名或选择器、<code>@property</code> 给变量声明类型与初始值
  （声明过才能参与动画）、命名建议（按用途而非颜色值）、别把什么都做成变量。

## 本批的三处“实测校准”

1. **过渡会骗过断言（第三次遇到）**：例 4 点击切换主题后立刻读计算样式，颜色还没走完过渡
   （背景仍是浅色），一度像“切换没生效”；例 5 的 <code>--scale</code> 也是同理。
   加 500–700ms 等待后复测：主题色切到 <code>rgb(23,24,29)</code> 一档、
   强调色精确变为 <code>#d46a5d</code>；<code>--scale: 1.8</code> 时内边距 20.16px、
   字号 24.48px、圆角 14.4px，正是 <code>0.7rem/0.85rem/8px × 1.8</code> 的结果。
2. **边框宽度会被取整**：<code>calc(1px * 1.8)</code> 实测计算值是 **1px**——
   浏览器把 border-width 取整到整数像素。演示文案据此改成
   “边框粗细也由它算出来，只是浏览器会取整到整数像素”，避免读者以为变量失效。
3. **`check-demo-classes.py` 第三次拦下真问题**：本式演示里写了 `.badge` 与 `.row`
   （Bootstrap 都有），当场报错后改成 `.d-badge` / `.d-row`。
