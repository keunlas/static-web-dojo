## 本批的自查

1. **抓出一处求值顺序问题**：例 2 里
   <code>say2('…' + trace2.join(' → ') + '…' + withFinallyReturn() + '…')</code>
   先把空轨迹读了进去、才去调用函数，于是输出成了「finally 不影响返回值：，函数返回…」——
   典型的“先读后写”。改为先 <code>var finallyResult = withFinallyReturn();</code>
   再拼字符串，复验为「try → finally」。
2. **确认 console.error 不会被自查工具误判**：例 4 会主动调用
   <code>console.error</code> 与失败的 <code>console.assert</code>（教学需要），
   实测 CDP 的标记检查仍报“错误: 无”——因为工具监听的是
   <code>Log.entryAdded</code>（网络/浏览器级）与 <code>Runtime.exceptionThrown</code>（未捕获异常），
   而 console API 走的是另一条通道。页面里也写明了“这是演示输出”，避免读者误以为页面坏了。
3. 四个演示逐行读出核对（含七种错误的文案），与正文表格一一对应。
