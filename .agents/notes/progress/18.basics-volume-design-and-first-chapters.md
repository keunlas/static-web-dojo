## 背景（用户新目标）

用户为项目定了新目标：**补完基础篇**。理由与要求（原文摘要）：

- 现状（直接让读者去 MDN 学）破坏了学习连贯性，MDN 内容多、新手不好组织分类入门；
- 本教程要既给初学者用，也能在出山后当字典查；
- 所有与纯静态网页相关的基础（HTML + CSS + JS，含 HTML5 / CSS3 等现代标准）都要在基础篇成文；
- 编写原则：从入门到进阶、可当字典、内容正确（错误不可容忍）、全面不片面、可优化现有内容。

据此把第一回从「MDN 引路」改为**43 式全程教程**，MDN 降为每部分末尾的「课外阅读」。
