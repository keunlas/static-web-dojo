## 本批完成的事

1. **`site/basics/11-html-a11y.html` 无障碍**（3 个演示 + 3 道练功）：
   - 无障碍服务谁（暂时受伤 / 环境 / 设备 / 长期状态）与“坡道效应”；
   - 第一条规矩「语义优先」：例 1 用**假按钮（span）vs 真按钮（button）**并排对比——
     假按钮 Tab 走不到、回车按不动，真按钮自带键盘行为与 `:focus-visible`；
   - 给“没有文字的东西”起名字的对照表（`alt` / `aria-label` / `aria-hidden="true"`），
     例 2 用三个图标按钮演示“没有名字 / 有 aria-label / 有可见文字”的区别（脚本读出可访问名称）；
   - 键盘三件事（走得到 / 看得见焦点 / 跳得过去）+ 本站 `.skip-link` 的结构块；
   - 表单三件套：<code>label</code>、<code>aria-describedby</code>、<code>role="status"</code>（例 3 实演自动播报）；
   - ARIA 属性表与**三条戒律**（能用原生就别 ARIA、不要用 ARIA 撒谎、
     `aria-hidden` 不能盖住可聚焦元素）；
   - 对比度（正文 4.5:1、大字号与图形 3:1）、`prefers-reduced-motion`，
     以及**五问自测清单**（键盘 / 200% 缩放 / 关图片 / 灰度 / 名字是否像人话）。
