## 本批完成的事

**`site/basics/07-html-forms-1.html` 表单（上）**（3 个演示 + 3 道练功）：

- 表单里的两个角色（读者要看得懂、机器要收得全）与**本站无后端**的现实说明
  （演示一律用脚本拦住真实提交，就地显示结果）；
- `form` 属性表（`action` / `method` / `enctype` / `target` / `novalidate`）
  与 **GET vs POST 对照表**（数据放哪、适合什么、能否分享；安全性的准确表述：
  POST 不上网址 ≠ 加密，加密靠 HTTPS）；
- `label` 的两种绑定写法（`for` + `id`、包裹式）与「placeholder 不是标签」心法；
- 文本类 `input` 类型表（text / search / email / tel / url / password / number，
  含“手机上键盘会怎样”）+ 属性表（重点标出 **漏写 name 等于白干**，
  以及 readonly 会提交、disabled 不会提交的区别）；
- 三种按钮（submit 默认 / reset 恢复初始值 / button 交给脚本）与
  「新代码统一用 button，不用 `input type="submit"`」的建议；
- 三个最容易白干的错误清单。

## 写法说明（本批确立、后续表单章沿用）

- 演示里的表单**不真的提交**：在预览的 `<script>` 里用 `event.preventDefault()`
  拦下 submit，把结果写进同演示的输出段落——既能让读者点得出效果，又不会把页面跳走；
- 交互脚本放在被操作元素**之后**的裸 `<script>` 里（与基础篇 JS 演示同一形态），
  源码块配 `data-lang="js"`，parity 会逐字比对；
- 脚本里只用 `document.getElementById` / `addEventListener` 这类原生 API，
  并注明“JS 篇会细讲”，不提前引入 jQuery。
