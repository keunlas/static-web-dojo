# 文风与视觉规范（style-guide）

> 写给 AI 代理：让新写的章节读起来、看起来与打样一致。

## 1. 文风

- **语气**：平实亲切的老师，不端着；对读者说“你”。
- **隐喻**：轻量使用“江湖/修行”意象（招式、心法、修炼、藏经阁、轻剑），
  每章章首语 1–3 句 + 每章 1–2 处点到为止即可，**不要堆砌**，技术讲解部分保持严肃准确。
- **节奏**：先讲“是什么/为什么”，再给演示，最后练功。定义→例子→练习。
- **体量**：每章正文（不含源码块）约 800–1500 字；小节短、句子短。
- **数字与术语**：类名、标签、属性一律 `<code>`；首次出现的术语给一句白话解释。
- **常见句式参考**（打样）：
  - 章首语：「江湖传言，写网页有三苦：……有一位前辈不忍后辈受苦……」
  - 心法：「<div class="callout warn">…… 心法：……</div>」
  - 预告：「下一式，我们修炼……」
  - 鼓励：「敲错了不丢人——报错信息是浏览器在给你指点迷津。」

## 2. 术语约定（全站统一）

| 术语 | 约定写法 |
| --- | --- |
| Bootstrap 版本 | Bootstrap 5.3.8（教程中简称 Bootstrap） |
| jQuery 版本 | jQuery 4.0.0（教程中简称 jQuery） |
| 章节 | “第 X 式”（Bootstrap 18 式 = 正篇 16 + 补遗 2；jQuery 14 式 = 正篇 10 + 补遗 4） |
| 分卷 | “第 X 回” |
| 栅格 | container 容器 / row 行 / col 列 / 十二列系统 / 断点 |
| gutter | 列间距（首次出现附英文 gutter） |
| bundle 版 | “bundle 捆绑包（内含 Popper 定位库）” |
| 就绪事件 | `$(document).ready` / 简写 `$(function(){…})` |
| 演示 | “现场演示”“例 N” |
| 练习 | “练功”，题目标“练功 · 第 X 式” |
| 附录 | “藏经阁”（含自编的「工具类速查」与「jQuery 方法速查」两页，与第三方离线文档同属查阅系列） |

## 3. 纸墨风视觉变量（site.css 已定义）

```css
--paper:#faf6ec  宣纸米白（页面底）
--paper-2:#f4edde 旧纸（侧边栏/区块底）
--paper-card:#fffdf7 新纸（卡片/演示底）
--ink:#2b2a26    浓墨（正文）
--ink-soft:#6f6a5e 淡墨（次要文字）
--cinnabar:#b03a2e 朱砂（强调/印章/链接）
--cinnabar-deep:#8f2f24
--line:#e3dcc8   淡墨线（边框）
--night:#20242e  墨夜（代码块底）
```

- 标题宋体系（Songti SC / Noto Serif CJK SC / SimSun），正文系统无衬线，代码等宽栈；
- 按钮主色即朱砂（`btn-primary` 已被覆盖），次要动作用 `btn-outline-primary`；
- 演示预览区底色是纸白 `#fffdf7`，演示里的配色建议用 Bootstrap 标准色系即可，
  避免大块荧光色；代码块永远墨夜底浅字；
- **暗色模式**（`<html data-bs-theme="dark">`，loader 自动应用/跟随系统）下整站配色
  有对应的暗夜版变量（纸 → `#17181d`、墨 → `#e6e1d2`、朱砂 → `#d46a5d`…），
  全部在 `site.css` 的 `html[data-bs-theme="dark"]` 块里；**写新样式时务必用变量取色**，
  不要写死明暗通用不了的颜色值，暗色下需要区分再补一个暗版覆盖。

## 4. 演示内容审美

- 演示文案贴合修行主题（“你好，江湖！”、“日拱一卒”等）但不做作；
- 演示要**小**：一个演示只讲清一件事，避免把三个知识点塞进一个例子里；
- 演示预览里的文字用 `mb-0`/`mt-3` 等工具类控制留白，别让内容顶边。

## 5. 页面标题与 description 格式

```
<title>第X式 · 章节名 | 第X回 XXX篇 | 纯静态网页的修行</title>
<meta name="description" content="本式讲什么，一句话。">
```

分卷页：`<title>第X回 · XXX篇 | 纯静态网页的修行</title>`。
